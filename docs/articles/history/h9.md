# 阿拉伯文明

> 在波斯与拜占庭两败俱伤的七世纪，阿拉伯半岛的沙漠部落携新信仰而出，四十年间建成横跨三洲的帝国。

## 概述

阿拉伯文明的崛起是世界史最戏剧性的转折之一：罗马（拜占庭）与波斯（萨珊）四个世纪的拉锯战刚刚耗尽双方（见[古罗马](articles/history/h6.md)、[波斯帝国](articles/history/h4.md)），半岛上携带新信仰的阿拉伯人便乘虚而出。此后伊斯兰文明不仅接管了波斯的旧土与罗马的东方行省，还把希腊、波斯、印度的学术熔于一炉，在中世纪充当了人类知识的"备份硬盘"与"转运枢纽"。

## 伊斯兰前的阿拉伯半岛

- 半岛以游牧的**贝都因人**部落为主，血缘氏族是最高的忠诚单位，诗歌是最大的荣耀载体——每年集市上的诗歌赛会，是阿拉伯人的"文化奥运"。
- **麦加**是商路与朝圣的枢纽，克尔白神殿供奉三百六十尊部落偶像，执掌者为古莱氏部族。
- 也门一带曾有示巴王国（"示巴女王"传说）与马里卜水坝灌溉文明，水坝溃坏后农业衰败，南阿拉伯人四散北迁。

## 穆罕默德与信仰的诞生（570—632）

- 约 570 年穆罕默德生于麦加古莱氏哈希姆家族，早年为商队经纪人；约 610 年起在希拉山洞接受启示，宣讲独一真主安拉、末日审判与济贫行善。
- 迁麦地那（**希吉拉，622 年**）：因受麦加贵族迫害，穆罕默德应邀北迁麦地那，建立政教合一的公社。此年被定为伊斯兰历元年——今天的"回历"纪年即从此起算。
- 630 年和平收复麦加，清除克尔白偶像但保留圣殿；632 年归真时，阿拉伯半岛已基本统一于新信仰之下。
- 《古兰经》经后世收集定本，成为阿拉伯语的定型之作——一种语言随一部经典变成了跨越洲际的文明载体。

## 四大哈里发与大征服（632—661）

| 哈里发 | 主要事迹 |
| ------ | -------- |
| 艾布·伯克尔 | 平定半岛叛乱（里达战争），首个"哈里发"（继任者）称号确立 |
| 欧麦尔 | 大征服高潮：636 年雅穆克之战破拜占庭、卡迪西娅之战破萨珊；638 年入耶路撒冷 |
| 奥斯曼 | 编定《古兰经》标准本；656 年遇刺引发第一次内战 |
| 阿里 | 先知堂弟兼女婿，与叙利亚总督穆阿维叶长期对抗，661 年遇刺 |

- 阿里之死埋下教派分裂的种子：承认前三位哈里发与既成秩序者成为**逊尼派**主流；认为只有阿里一系才是正统继承者者形成**什叶派**。680 年阿里之子侯赛因死于卡尔巴拉，此悲剧至今仍是什叶派最深的记忆节点。
- 大征服的逻辑：两大帝国精疲力竭、埃及与叙利亚民众对重税宗争不满、阿拉伯人从部落劫掠升级为国家性扩张——三者叠加，使看似不可能的征服变成了闪电战。

## 倭马亚王朝（661—750，中国称"白衣大食"）

- 穆阿维叶建都大马士革，哈里发位改为家族世袭——帝国开始像帝国。
- 东进中亚（751 年**怛罗斯之战**击败唐朝安西军，被俘工匠将造纸术带入撒马尔罕，一路西传），西取北非，711 年塔里克渡海峡入西班牙（"直布罗陀"即"塔里克之山"的音译），732 年普瓦蒂埃之战止步于法兰克。
- 中国史籍因其尚白而称**白衣大食**；玄奘取经时代的中亚商路上，正是这股新势力在改写地图。

## 阿拔斯王朝（750—1258，中国称"黑衣大食"）

- 750 年以呼罗珊为基地的革命推翻倭马亚（一支倭马亚余脉逃亡西班牙建立后倭马亚王朝），762 年曼苏尔营建圆形新都**巴格达**，"天下商埠之冠"。
- 因尚黑，中国称**黑衣大食**。《一千零一夜》里无数故事发生于此朝。

### 百年翻译运动与智慧宫

- 哈里发**马蒙**（813—833）设**智慧宫**（Bayt al-Hikma），倾国之力把希腊哲学与科学（亚里士多德、托勒密、欧几里得、盖伦）、波斯典籍（《列王纪》母本、《千篇故事》）、印度天文与数学译为阿拉伯文。
- 译者大师侯奈因·本·伊斯哈格按页计酬以黄金——学术翻译史上第一次"按字付费"。
- 延伸：8—10 世纪，希腊原典在欧洲已基本失传，正是这批阿拉伯译本（后经西班牙托莱多与西西里的二次翻译）把亚里士多德与欧几里得还给欧洲，直接喂养了 12 世纪文艺复兴与后来的近代科学——阿拉伯文明是古典知识的中转仓与增值站。

### 科学的黄金时代

- **花剌子模**（al-Khwarizmi）：代数学之父，"代数（algebra）"来自其书名《还原与对消计算概要》，"算法（algorithm）"来自其名字的拉丁转写——一个名字两次进入现代计算机科学的词根。
- **拉齐斯（拉齐，al-Razi，854—925）**：巴格达医院院长，率先区分天花与麻疹，著《医学集成》与《秘典》；其集体式的大医院查房制度是中世纪医学教育的标杆。
- **伊本·西那（阿维森纳，980—1037）**：《医典》沿用至 17 世纪的欧洲医学院；哲学上的"存在的论证"影响了从托马斯·阿奎那到近代哲学。
- **伊本·海赛姆（海桑，965—1040）**：《光学书》以实验否定"眼睛发光说"，被视为实验科学方法的前驱；其光学传入欧洲影响了开普勒与牛顿。
- **比鲁尼**：测地球半径、研究印度文明（《印度志》），堪称 comparative 人类学第一人；**花剌子密天文表**、星盘、天文台则服务于航海、历法与礼拜方位——科学与信仰在此并不矛盾。

### 一千零一夜（天方夜谭）

- 故事框架源自波斯《赫扎尔·阿夫萨奈》（"千篇故事"），在阿拔斯时代的巴格达与开罗、马穆鲁克时代不断增补成书：山鲁佐德讲故事免死一千零一夜，辛巴达航海、阿拉丁神灯、阿里巴巴与四十大盗皆在其中。
- 中国因传自西域而称其"天方夜谭"（"天方"即麦加的旧译）。18 世纪加朗的法译本风靡欧洲，直接启发了浪漫主义文学——这本"东方故事集"成了欧洲人想象东方的第一扇窗。

## 安达卢斯：欧洲的伊斯兰文明

- 756—1031 年后倭马亚王朝治下的**科尔多瓦**是欧洲最大最文明的城市之一：数十万人口、数百座清真寺与浴场、藏书四十万卷的皇家图书馆（当时欧洲王室的藏书以"百"计）。
- 穆斯林、犹太人、基督徒共处的" convivencia（共存）"时代：犹太学者、阿拉伯科学家与拉丁修士在**托莱多翻译学校**接力，把阿拉伯文典籍译成拉丁文——欧洲人由此重新拿回亚里士多德，也第一次系统读到代数与医学。
- 建筑遗产：科尔多瓦大清真寺的紅白拱林、格拉纳达**阿尔罕布拉宫**的蜂窝穹顶与庭院水法，是伊斯兰艺术在西欧的巅峰之作；1492 年格拉纳达陷落，穆斯林对伊比利亚七百年的统治终结。

## 中世纪中东的群雄更替

- **法蒂玛王朝**（909—1171，什叶派）：970 年建**爱资哈尔清真寺**（今爱资哈尔大学，伊斯兰最高学府之一），969 年建**开罗**城。
- **塞尔柱突厥**：1071 年**曼齐刻尔特之战**大败拜占庭，小亚细亚从此突厥化；震动欧洲，成为十字军东征的诱因之一。
- **十字军东征（1096—1291）**：欧洲以"收复圣地"之名两百年间八次东征，1099 年血洗耶路撒冷。1187 年**萨拉丁**在哈丁之战全歼十字军主力、收复耶路撒冷——他赦免居民、禁杀降俘的作风，连对手狮心王理查也敬佩有加，成为骑士精神的东方定义者。
- **马穆鲁克王朝**：奴隶出身的军人集团统治埃及，1260 年**艾因·贾鲁特之战**击败所向披靡的蒙古军——蒙古西征的停止线画在巴勒斯坦。

## 蒙古西征与巴格达陷落（1258）

- 1258 年旭烈兀攻陷巴格达：末代哈里发被裹毯纵马踏死，智慧宫与图书馆付之一炬，传说底格里斯河水一度被墨染黑。
- 阿拔斯帝统终结，但伊利汗国其后改宗伊斯兰；中东的政治重心转向埃及（马穆鲁克）与小亚细亚——那里有一个不起眼的小侯国，首领名叫**奥斯曼**。

## 奥斯曼帝国（1299—1922，简述）

- 奥斯曼侯国经巴耶济德、穆拉德二世稳步扩张；**穆罕默德二世** 1453 年以乌尔班巨炮与旱地行舟的舰队攻陷**君士坦丁堡**——千年拜占庭落幕（见[古罗马](articles/history/h6.md)），帝国定都伊斯坦布尔，圣索菲亚大教堂改为清真寺。
- 1517 年塞利姆一世征服埃及马穆鲁克，把麦加、麦地那两圣地的监护权与哈里发头衔收入囊中；**苏莱曼大帝**（1520—1566）时代帝国兵临维也纳城下，法典（苏莱曼法典）、伊斯坦布尔的苏莱曼尼耶清真寺与地中海霸权俱在其手。
- 一战后帝国解体，1922 年苏丹制废除——一个跨越六个世纪、终结中世纪的帝国退场。

## 延伸拓展

- **"阿拉伯数字"的误会**：数字符号是印度发明（见[印度文明](articles/history/h7.md)），十进制与位值经阿拉伯学者（花剌子模、肯迪学派）吸收改良，斐波那契 1202 年《计算之书》把它带进欧洲商界——名字记录的只是这条传播链的中转站。
- **语言与词汇**：algebra（代数）、algorithm（算法）、alchemy/chemistry（炼金/化学）、alcohol、zero、admiral、coffee、cotton、sugar——英语里一长串"al-"开头的词，都是中世纪知识转运站的印章。
- **咖啡**：也门苏菲派为夜间诵经而饮，15 世纪传到开罗、伊斯坦布尔，17 世纪进入欧洲咖啡馆——从修道院饮品到启蒙运动的"思想交易所"，咖啡的全球化本身就是一部微缩文明史。
- **贸易与地理**：阿拉伯商人垄断了从摩鹿加香料到西非黄金的印度洋—地中海网络，《马可·波罗游记》的畅销正建立在阿拉伯商路给欧洲人的想象上；达伽马绕过好望角（1498）打破垄断，才是大航海时代真正开始（见[印度文明](articles/history/h7.md)）。
- **思考**：为什么中世纪的"科学外包"发生在阿拉伯而非当时更富庶的拜占庭或中国？——多元文明交汇（希腊、波斯、印度三种学术传统同时在场）+ 翻译运动的制度激励 + 商业网络带来的跨国学术共同体，三者缺一不可。文明的高峰常出现在"接口"处，而非"核心区"。
