# 世界通史 · 总览

历史不是往事的堆积，而是人类理解自身的一把钥匙。这个模块按照**文明**为单元拆分，把散落在各大洲的古国故事串成一条可以对照阅读的时间线：古埃及、两河文明、波斯帝国、古希腊、古罗马、印度文明、美洲文明、阿拉伯文明。

## 历史分期

通行的世界史分期大致如下，本模块的文章主要覆盖古代史与中世纪部分：

| 分期 | 大致时间 | 关键词 |
| ---- | -------- | ------ |
| 史前时代 | 文字出现之前 | 采集渔猎、农业革命、部落 |
| 古代史 | 约前 3500 年—476 年 | 四大古文明、城邦、帝国、轴心时代 |
| 中世纪 | 476 年—1453 年 | 封建制度、宗教文明、拜占庭、阿拉伯、唐宋 |
| 近现代 | 1453 年至今 | 大航海、工业革命、民族国家、全球化 |

## 四大古文明对照

| 维度 | 古埃及 | 两河文明 | 古印度 | 古代中国 |

| 母亲河 | 尼罗河 | 底格里斯河、幼发拉底河 | 印度河、恒河 | 黄河、长江 |
| 文字 | 象形文字 | 楔形文字 | 印度河印章文字（未破译）→ 梵文 | 甲骨文 |
| 代表建筑 | 金字塔、神庙 | 塔庙（Ziggurat）、空中花园 | 摩亨佐-达罗浴池、阿育王石柱 | 长城、宫殿 |

## 为什么"轴心时代"如此重要

德国哲学家雅斯贝尔斯提出：大约公元前 800—前 200 年之间，各文明几乎同时出现精神的突破——

- 希腊：苏格拉底、柏拉图、亚里士多德的理性哲学
- 印度：释迦牟尼与大雄的宗教革新
- 中国：孔子、老子的伦理与思辨
- 波斯：琐罗亚斯德教的善恶二元观

今天人类的精神底色，很大程度上仍是这几条根脉的延伸。理解这段"共同青春期"，是读懂整个世界史的捷径。

## 延伸思考

- **文明的引擎是什么？** 大河灌溉（四大古文明）、海洋贸易（希腊、腓尼基）、军事组织（亚述、罗马）各有答案。
- **帝国为何总是兴衰循环？** 扩张红利递减、继承制度不稳、边疆压力增大是常见的组合因素。
- **文字为何是文明的第一道门槛？** 它让行政管理、法律与思想可以脱离人脑传承，文明因此可以"存档"。
