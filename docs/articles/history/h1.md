# 世界通史 · 总览

历史不是往事的堆积，而是人类理解自身的一把钥匙。世界通史按照**时间顺序**梳理人类社会的变化，再以文明专题补充不同地区的经验：从史前生活、农业和早期国家，到中世纪的区域交流、近代革命与工业化，再到世界大战、冷战和全球化。

阅读时可先按下方目录顺序建立时间线；遇到感兴趣的文明，再进入古埃及、两河、印度、希腊、罗马、美洲和阿拉伯等专题。分期是帮助理解的工具，不同地区并非同步进入同一个“时代”。

## 历史分期

通行的世界史分期大致如下。各地区的发展节奏不同，表中的年代只是便于学习的参照：

| 分期 | 大致时间 | 关键词 |
| ---- | -------- | ------ |
| 史前时代 | 文字出现以前 | 人类迁徙、采集狩猎、农业与定居 |
| 古代世界 | 约前 3500 年起，各地结束时间不同 | 城市、文字、早期国家、古典文明与帝国 |
| 中世纪及区域文明 | 欧洲史常以 5—15 世纪为参照，地区差异很大 | 欧洲、亚洲、非洲和美洲的政权、宗教与贸易网络 |
| 近代早期 | 约 14—18 世纪 | 文艺复兴、宗教改革、远洋航路与革命 |
| 工业化与帝国扩张 | 约 18 世纪后期至 1914 年 | 工业革命、民族国家、社会主义与殖民扩张 |
| 当代世界 | 20 世纪至今 | 世界大战、冷战、非殖民化与全球化 |

## 四大古文明对照

| 维度 | 古埃及 | 两河文明 | 古印度 | 古代中国 |
| ---- | ------ | -------- | ------ | -------- |
| 母亲河 | 尼罗河 | 底格里斯河、幼发拉底河 | 印度河、恒河 | 黄河、长江 |
| 文字 | 象形文字 | 楔形文字 | 印度河印章文字（未破译）；后世梵文文献 | 甲骨文 |
| 代表建筑 | 金字塔、神庙 | 塔庙（Ziggurat）、空中花园 | 摩亨佐-达罗浴池、阿育王石柱 | 长城、宫殿 |
| 社会秩序 | 王权、神庙与习惯 | 《汉谟拉比法典》等成文法 | 瓦尔纳分层与多种宗教、法律传统 | 礼制与刑法 |
| 宗教 | 多神与来世信仰 | 多神、占星 | 婆罗门教→佛教 | 祖先崇拜→诸子百家 |
| 纪年要点 | 前3100 统一 | 前2334 阿卡德帝国 | 前2600 哈拉帕文化 | 前2070 夏（推算） |

## 为什么"轴心时代"如此重要

德国哲学家雅斯贝尔斯提出：大约公元前 800—前 200 年之间，各文明几乎同时出现精神的突破——

- 希腊：苏格拉底、柏拉图、亚里士多德的理性哲学
- 印度：释迦牟尼与大雄的宗教革新
- 中国：孔子、老子的伦理与思辨
- 波斯：琐罗亚斯德教的善恶二元观

今天人类的精神底色，很大程度上仍是这几条根脉的延伸。理解这段"共同青春期"，是读懂整个世界史的捷径。

## 延伸思考

- **文明的引擎是什么？** 大河灌溉（四大古文明）、海洋贸易（希腊、腓尼基）、军事组织（亚述、罗马）各有答案。
- **帝国为何总是兴衰循环？** 扩张红利递减、继承制度不稳、边疆压力增大是常见的组合因素。
- **文字为何是文明的第一道门槛？** 它让行政管理、法律与思想可以脱离人脑传承，文明因此可以"存档"。
- **怎样把世界史读连贯？** 先读时间线文章，再看文明专题；比较交流与冲突，不把某一地区的分期当成全世界统一的钟表。
