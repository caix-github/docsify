# 古埃及

> "埃及是尼罗河的赠礼。" —— 希罗多德

## 概述

古埃及是世界上最悠久的连续文明之一。约公元前 3100 年，纳尔迈（传说中的美尼斯）统一上下埃及，此后三千年间历经三十余个王朝，直到公元前 30 年托勒密王朝末代女王克利奥帕特拉七世自杀，埃及并入罗马版图。金字塔、木乃伊、象形文字与法老的传说，共同构成了这个"活人与死人共享的国度"。

## 地理底色：一条河决定一个文明

- **尼罗河**自南向北纵贯全境，每年 7—10 月定期泛滥，洪水退去留下肥沃的黑色淤泥（"凯麦特"，意为黑土地）。
- 两侧是沙漠（"红土地"），天然屏障使埃及极少遭受外族侵扰，文明得以超长待机。
- 全境天然分为**上埃及**（南方河谷）与**下埃及**（北方三角洲）。王冠也分两种：上埃及的白色高冠与下埃及的红色扁冠，法老戴的"双冠"象征对两地的统治——"上下埃及之王"是历代国王的头衔之一。

## 王朝分期（国王表速览）

| 时期 | 大致年代 | 代表人物与事件 |
| ---- | -------- | -------------- |
| 早王朝时代 | 前3100—前2686 | 纳尔迈统一、第一二王朝 |
| 古王国（金字塔时代） | 前2686—前2181 | 左塞尔阶梯金字塔、胡夫大金字塔、狮身人面像 |
| 第一中间期 | 前2181—前2055 | 王权崩解、地方割据 |
| 中王国 | 前2055—前1650 | 孟图霍特普二世再统一、文学繁荣 |
| 第二中间期 | 前1650—前1550 | 希克索斯人（亚洲移民）入主北方，带来战车 |
| 新王国（帝国时代） | 前1550—前1070 | 哈特谢普苏特、图特摩斯三世、埃赫那吞宗教改革、图坦卡蒙、拉美西斯二世 |
| 第三中间期与后王朝 | 前1070—前332 | 利比亚人、努比亚人、波斯人相继统治 |
| 希腊化时期 | 前332—前30 | 亚历山大建亚历山大城，托勒密王朝，埃及艳后 |

延伸一个易被忽略的点：埃及的"王朝"由曼涅托（托勒密时代的埃及祭司）划分，沿用至今。所谓"第三十一王朝"并非严密的谱系，而是以统治家族更迭为线索的分期工具。

## 金字塔：为永恒而建

- 金字塔是法老的陵墓，演化自平顶长方形墓"马斯塔巴"。约前 2630 年，建筑师伊姆霍特普为左塞尔王建造六层阶梯金字塔，是现存最早的石造大型建筑。
- 吉萨的**胡夫大金字塔**约建于前 2560 年，由约 230 万块巨石垒成，原高 146.6 米，是此后近四千年间世界最高建筑。
- 建造者并非传说中"奴隶大军的皮鞭产物"：工人村遗址显示，雇佣的农民与工匠有面包、啤酒供给，甚至享有医疗。
- 狮身人面像（斯芬克斯）守在哈夫拉金字塔前，是王权与智慧的合体。

延伸：金字塔选址在尼罗河西岸——太阳落下的方向，对应冥界。整座建筑群就是一部"石化的来世手册"。

## 众神与来世观

埃及是多神教世界，神祇动辄兽首人身：

- **拉**：太阳神，国王自称"拉之子"。
- **奥西里斯与伊西斯**：死而复生神话的原型，奥西里斯主持冥界审判。
- **荷鲁斯**：鹰神，在世的法老就是他人间的化身。
- **阿努比斯**：胡狼神，木乃伊制作的主保神。

来世信仰催生了两大技术传统：

1. **木乃伊**：取内脏（存于四个卡诺卜坛）、泡碱脱水、亚麻包裹，历时约 70 天。心脏留在体内，因为要放在天平上与"真理之羽"称量。
2. **《亡灵书》**：随葬的咒语手册，指导死者通过冥界重重关卡，通过"称心仪式"即可永生。

## 文字与纸草：埃及学的钥匙

- **象形文字**（圣书体）约出现于前 3200 年前后，兼具表意与表音，常刻于神庙与陵墓；日常书写用祭司体、世俗体，写在**莎草纸**上——古代世界最轻便的书写材料之一。
- 罗马关闭埃及神庙后，无人再识得象形文字，埃及史沉寂了上千年。转机出现在 1799 年：拿破仑军队在罗塞塔镇挖工事时挖出一段石碑，同一段王令分别用圣书体、世俗体与希腊文刻写。
- 1822 年，法国学者**商博良**借助托勒密王名圈（椭圆框）比对破译成功，埃及学由此诞生。一个失落的文明第一次能"亲口讲述"自己。

## 新王国的荣光：帝国、改革与传奇

新王国（第十八至二十王朝）是埃及的帝国时代，本图所列几位"明星法老"多出于此：

- **哈特谢普苏特**：女法老，穿男装戴假须执政二十余年，远征蓬特（红海贸易）。
- **图特摩斯三世**：美吉多之战后十七次远征西亚，把版图推至幼发拉底河。
- **埃赫那吞**：前 14 世纪推行史上最早的"一神改革"，独尊太阳神阿吞，迁都阿玛尔纳；改革随其去世瓦解。
- **图坦卡蒙**：埃赫那吞之子，18 岁即亡，本是默默无闻的小王，却因陵墓未被盗掘而在三千年后成为"最著名的法老"。
- **拉美西斯二世**：在位 66 年，寿至九十余；与赫梯大战于卡迭石（前 1274），随后签订人类已知最早的和平条约（《银板和约》）；阿布辛贝神庙是他的纪念碑，1960 年代为避阿斯旺水库整体搬迁，成为世界文物保护史上的标志性事件。

### 图坦卡蒙的发现

1922 年，英国考古学家霍华德·卡特在帝王谷打开 KV62 号墓，镜头记录下他那句著名的话："我看见了美好的事物。"墓中五千余件文物（黄金面具、宝座、战车……）轰动世界。随后"法老的诅咒"传说不胫而走——实际上主要资助人卡纳冯勋爵死于病,而卡特本人又活了十几年。传说归传说，这座墓的科学价值在于：它是帝王谷中唯一基本完好的王室墓葬，让今人第一次"原位"看到法老葬制的全貌。

### 埃及艳后

克利奥帕特拉七世（前 69—前 30）是托勒密王朝末代君主，马其顿裔却以会说埃及语、亲习埃及礼仪著称。她先后与恺撒、安东尼结盟以保全埃及；公元前 31 年亚克兴海战失败后，屋大维进军埃及，她自尽身亡，古埃及的独立史至此终结。她并非以美貌闻名于当世，而是以口才、语言天赋（通多国语言）与政治手腕著称——莎士比亚笔下的形象是后世的再创作。

## 延伸拓展

- **太阳历**：埃及人依据天狼星偕日升与尼罗河泛滥的对应关系，制定 365 天历法（12 个月×30 天+5 个节日），是今天公历的远祖之一。
- **医学**：埃伯斯纸草等记录了大量药物与外科处置，拥有专业化的"医生"职业分工。
- **数学**：为丈量泛滥后的土地，发展出实用几何（圆周率取 3.16、分数运算）。
- **《圣经·出埃及记》**：摩西率希伯来人出埃及的故事发生在传统上拉美西斯二世或其继承者在位时期；考古学界对此尚无定论，但"出埃及"叙事对犹太民族认同影响至深，可结合[两河文明](h3.md)中以色列王国一节对照阅读。
- **未解之谜**：斯芬克斯的确切年代、金字塔精确施工方式、阿玛尔纳时代为何突然中断等，仍是活跃的研究话题。
