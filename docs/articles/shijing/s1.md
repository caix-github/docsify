# 诗经 · 导读总览

> "不学诗，无以言。" ——《论语·季氏》

《诗经》是中国最早的诗歌总集，收诗 305 篇（另有 6 篇有目无辞的"笙诗"），故又称"诗三百"。它上起西周初年，下至春秋中叶（约前 11 世纪—前 6 世纪），跨越五百年，由周王室采诗、献诗而成，经孔子整理传习，是先秦贵族教育的共同课本，也是华夏文学与情感教育的源头。

本模块按**主题**重新编排选段，把散在风、雅、颂里的同类之作并置比观，方便从"人情"而非"乐章"的入口读《诗》。

## 体例：风、雅、颂

| 类别 | 性质 | 篇数 | 代表 |
| ---- | ---- | ---- | ---- |
| 风（国风） | 十五国地方的民歌乐调 | 160 | 《关雎》《蒹葭》《氓》《桃夭》 |
| 雅（大雅、小雅） | 王畿之乐，正声，朝廷宴飨朝会之诗 | 105 | 《鹿鸣》《伐木》《采薇》《生民》 |
| 颂（周、鲁、商颂） | 宗庙祭祀之乐舞歌辞 | 40 | 《清庙》《维天之命》《鲁颂·駉》 |

- "风"是十五国风：周南、召南、邶、鄘、卫、王、郑、齐、魏、唐、秦、陈、桧、曹、豳。地域从黄河流域到江汉，民风各异。
- "雅"分大雅、小雅：大雅多朝会祭祀、史诗颂功；小雅多宴饮酬答、个人抒怀。
- "颂"是庙堂正乐，节奏舒缓庄重，配舞。

## 手法：赋、比、兴

| 手法 | 释义 | 例 |
| ---- | ---- | ---- |
| 赋 | 铺陈直叙 | 《七月》"七月流火，九月授衣" |
| 比 | 以彼物比此物（比喻） | 《硕鼠》"硕鼠硕鼠，无食我黍" |
| 兴 | 先言他物以引起所咏之词 | 《关雎》"关关雎鸠，在河之洲"起兴后咏"窈窕淑女" |

> 兴是《诗经》最独特的手法：起首的鸟兽草木与正意未必有逻辑联系，却定下了全诗的情绪底色。读《诗》常要先辨"兴"，再问"赋比"。

## 编集与流传

- **采诗说**：相传周王室派"行人""遒人"到民间采风，以观民风、知得失。
- **孔子删诗说**：相传孔子从三千余篇删定为三百，学界有争议，但他"皆弦歌之"整理《诗》乐当属事实。
- 汉代传《诗》者四家：齐（辕固）、鲁（申培）、韩（韩婴）、毛（毛公）。前三家先后亡佚，今所传为**毛诗**，故篇前皆有"毛诗序"（小序/大序），是理解古义的主要依据，也是后世聚讼之地。

## 怎样读本模块

1. 每首条目给出**出处**（风/雅/颂 + 国名）、笔记中的**原句**、**释义**、**解读**与**延伸**（成语、典故、后世影响）。
2. 部分名篇附较多全诗，便于体会"重章叠句"的复沓之美。
3. 同一首诗若分属不同主题（如《墙有茨》既讽刺又涉宫闱），会在相关主题中各引一节，并互相指引。
4. 主题分类参照学习笔记，是一种"以今读古"的方便法门，并非定论——同一首诗历来可有多种解读，阅读时不妨并存。

## 延伸：为什么今天仍要读《诗经》

- **汉语的母本**：成语如"信誓旦旦""一日不见如隔三秋""执子之手与子偕老""逃之夭夭（桃之夭夭）""未雨绸缪""小心翼翼"皆出于此；不读《诗》，许多词便不知其来处与原意。
- **情感的底片**：恋爱、思念、怨弃、劳作、宴饮、思乡——三千年前的喜怒哀乐与今人并无不同，《诗》的伟大在于用最朴素的语言为人类情感存照。
- **博物的标本**：孔子说学《诗》可"多识于鸟兽草木之名"。《诗》涉及动植物百余种，是上古自然与农业生活的活档案。
