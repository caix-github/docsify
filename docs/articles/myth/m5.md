# 毛利神话：天地分离与半神毛伊

毛利神话是新西兰原住民毛利人的口头传承，核心圣典是《玛纳提兰加》（Te Māoritanga）。它没有成文经典，依赖口耳相传，但故事结构极为完整。其创世神话——"天地分离"——与众多古文明的天地神话遥相呼应，但毛利神话中半神毛伊的"诡计英雄"形象，使其在世界神话中独树一帜。

## 一、毛利神话的总体特征

1. 万物有灵：毛利人相信所有自然物——河流、山川、树木、鸟类——都有自己的神圣守护者。
2. 血缘纽带：神、半神与人类之间通过血缘联结，部落首领常追溯祖神。
3. 口头传承：神话以吟唱、谚语、雕刻形式代代相传，雕刻中的螺旋、人形都是神话的"图书记录"。
4. 毛利神话最特别的一点，是神祇并不遥远——山就在那里，河就在身边，每一个地名都承载着神话。

## 二、创世神话：朗吉与帕帕的分离

最初的宇宙只有**天父朗吉**（Ranginui）和**地母帕帕**（Papatuanuku）。他们紧紧拥抱，世间一片黑暗。

他们的孩子被困在父母之间，无法伸展。最年轻的儿子**塔尼马胡塔**（Tane Mahuta），森林与鸟类之神，决定采取行动——他躺在地上，双脚撑住地母，双手顶住天父，用尽全身力气将父母撑开。

这一撑，光明进入世界，万物得以生长。朗吉被推上天空，化作天空之神；帕帕留在地上，化作大地之母。但天父与地母从未停止思念，朗吉的眼泪化作露水，帕帕的呜咽化作地热与泉涌。

这个"天地分离"神话与世界各地的创世神话遥相呼应：
- 中国的盘古开天辟地——盘古也是顶天立地，撑开天地；
- 苏美尔的阿普苏与提亚玛特——两水域交合生出众神；
- 希腊的乌拉诺斯与盖亚——天父地母的结合。

毛利神话的独特之处在于，分离天地的是塔尼马胡塔——一个具体的神祇，而非抽象的原初存在。这种"人格化的天地分离者"让神话更具故事性。

## 三、主要神祇

### 塔尼马胡塔（森林之神，大力神）

笔记中提到的**塔尼马胡塔**是毛利神话中最重要的大力神，森林与鸟类之神，也是撑开天地的英雄。他象征着生命、力量和自然的生机。新西兰最古老的贝壳杉树常被称为"塔尼马胡塔之主"，可见其崇拜之深。

### 图马陶允卡（战神）

笔记中的**图马陶允卡**是战神，掌管战争、狩猎、捕鱼和食物获取。毛利人视狩猎和战斗为同源——获取食物需要技巧与勇气，与战斗无本质区别。向图马陶允卡献祭能确保丰收与胜利。

### 朗吉与帕帕（天父地母）

朗吉与帕帕是最初的一对，他们既是世界本身，也是所有神的父母。毛利神话中，神祇与自然现象常常是同一个概念——朗吉就是天空，帕帕就是大地，而非"管理天空的神"或"管理大地的神"。

### 其他神祇

- 塔维里里（风神）
- 塔马努（海洋与渔业神）
- 鲁奥科（地震与火山之神）
- 希奈努伊泰波（夜之女神，死亡之母）——她在毛利神话中地位独特，是与死亡直接相关的女神

## 四、半神毛伊

毛利神话最著名的人物是半神**毛伊**（Maui），他是"诡计英雄"的原型。

### 毛伊的身世

毛伊出生时被母亲抛弃入海，被海神抚养。长大后他凭借智谋和魔法，完成了一系列造福人类的壮举。

### 毛伊的功绩

1. 拖起岛屿：毛伊用魔法鱼钩从海底钓起新西兰北岛（毛利语称"Te Ika-a-Māui"，意为"毛伊的鱼"）。
2. 减缓太阳：太阳移动太快，毛利人没有足够时间劳作。毛伊用绳套住太阳，威胁他减慢速度——从此白昼变长，人类有了耕作的时间。
3. 发现火的秘密：毛伊追问火神如何取火，最终偷到火种带给人类。
4. 寻求永生：毛伊最大的野心，是让人类战胜死亡。他试图钻入夜之女神希奈努伊泰波的身体，从她口中进入再出来，从而获得永生。但一只鸟嘲笑了他，希奈努伊泰波惊醒，把毛伊夹死。从此人类必须面对死亡。

毛伊神话的最后一节最富哲学意味：**人类之所以会死，是因为毛伊的失败**。死亡不是惩罚，而是"诡计英雄"最终无法战胜的对手。这与希腊神话中人类必死的设定形成对比——希腊神话的死亡来自神的判决，毛利神话的死亡来自一次失败的诡计。

## 五、毛利神话的现代意义

1. 新西兰的官方语言之一是毛利语，许多地名沿用毛利神话——如北岛被称为"毛伊的鱼"。
2. 毛利人的碰鼻礼（hongi）被认为共享了朗吉与帕帕分开时的生命之息。
3. 《海洋奇缘》中的半神毛伊就是这位传说人物——迪士尼将其推向全球。
4. 毛利神话的"天地分离"主题，为比较神话学提供了宝贵素材——它让我们看到，不同文明如何独立地产生相似的创世母题。

## 总结

毛利神话是波利尼西亚神话体系最丰富的一支，它兼具创世的庄严（天父地母的分离）和半神的灵动（毛伊的诡计）。

读毛利神话最大的震撼，是看到一个没有文字的社会，如何用口耳相传、雕刻和吟唱，把神话传了上千年而不失其完整。这种"用身体记忆传承文明"的方式，提醒我们文字并非文明的唯一载体。

从塔尼马胡塔撑开天地，到毛伊用鱼钩钓起北岛，再到希奈努伊泰波吞噬半神——毛利神话用最诗意的叙事，回答了人类最古老的问题：世界从何而来，人为何会死。
