# 印度神话：吠陀诸神与三相神

印度神话是人类最庞杂的神话体系之一，历经三千余年层层叠加：从早期吠陀的自然神崇拜，到后期印度教三相神（梵天、毗湿奴、湿婆）的成熟，再到两大史诗《罗摩衍那》《摩诃婆罗多》对英雄叙事的扩写。它没有"正典"单一文本，而是由四吠陀、往世书、两大史诗共同构成的层叠系统。

## 一、印度神话的总体特征

1. 多神而非一神：印度神话神祇数以万计，但最高实在"梵"（Brahman）贯穿其中，诸神被视为"梵"的不同面向。
2. 轮回与业力：人与神都在轮回之中，行为决定下辈子的形态——这一观念深刻影响了印度社会结构（种姓制度的宗教依据）。
3. 时代循环：印度神话相信世界经历四个纪元——圆满时代、三分时代、二分时代、争斗时代（Kali Yuga，即当今），周而复始。
4. 苦行（Tapas）的能量：苦行能产生实际的神力，连神也靠苦行增强自己——这是印度神话独有的观念。

## 二、吠陀神话：早期自然神

最早的印度神话见于**《梨俱吠陀》**（约公元前1500年），主要崇拜自然现象的人格化神祇。

### 因陀罗（雷神与战神）

因陀罗是吠陀时期最重要的神，是雷电、暴雨与战争之神。他手持金刚杵，骑着白象。最著名的事迹是用金刚杵斩杀蛇妖弗栗多，释放被其堵住的世界之水——这与希腊宙斯击败提坦、北欧索尔战巨蛇的故事异曲同工。

### 阿耆尼（火神）

火神阿耆尼是人与神之间的中介，祭祀之火即阿耆尼本身。吠陀祭祀就是通过阿耆尼把供物送达天界。

### 苏利耶（太阳神）与伐楼拿（律法神）

苏利耶是太阳神，每天驾金色马车穿越天空。伐楼拿是宇宙秩序（RTA）的守护者，也是海洋之神。他全知全能，被认为最早的神王。

### 苏摩（月神与酒神）

苏摩既是植物神，也是神圣饮料——祭祀用的苏摩酒就是他的化身，能赋予神与人力量和不朽。

## 三、后期印度教：三相神体系

约公元前500年起，印度神话进入"往世书"阶段，因陀罗的地位下降，三位至高神（Trimurti，三相神）确立：

### 梵天（创造之神）

梵天是宇宙的创造者，四面四臂，骑天鹅，从莲花中诞生。他创造了一切，但在民间崇拜中相对冷清——全印度只有几座专门供奉梵天的神庙（最著名在普什卡尔）。

### 毗湿奴（保护之神）

毗湿奴是宇宙的维护者，四臂持法螺、轮宝、莲花、神锤。他最大特点是"下凡"（Avatar，化身）——每当世界陷入混乱，毗湿奴就化身为不同形象下凡救世。

十大化身包括：
- 鱼（摩差，从洪水中救出人类始祖）
- 龟（俱利摩，搅拌乳海时作底座）
- 野猪（筏罗诃，从洪水救出大地）
- 人狮（那罗辛哈，诛杀暴君）
- 矮人（筏摩那，三步跨越三界）
- 持斧罗摩
- 罗摩（即《罗摩衍那》主角）
- 黑天（即《摩诃婆罗多》中的克里希那）
- 佛陀（印度教将佛陀纳入其化身体系）
- 白马迦尔基（末世将降临的救世主）

### 湿婆（毁灭与再生之神）

湿婆是宇宙毁灭与重生的神，第三只眼能喷射毁灭之火。他住在火葬场，身上涂灰，颈缠蛇，是瑜伽行者之神。湿婆的"林伽"（男根）是其崇拜的核心符号，象征创造能量。

湿婆之子有象头神伽内什（智慧与障碍之神，全印度最受欢迎的家宅神）和战神室建陀。

### 三相神的关系

三相神不是分裂的三个神，而是同一个最高实在的三个面向：梵天创世、毗湿奴维持、湿婆毁灭，三者循环往复，构成宇宙的"成住坏空"。这一观念与中国佛教"劫"的概念高度相通。

## 四、两大史诗

### 《罗摩衍那》

《罗摩衍那》讲述阿逾陀王子罗摩被流放14年，妻子悉多被魔王罗波那掳走，在猴神哈奴曼帮助下救回妻子的故事。

哈奴曼是印度神话中最受欢迎的猴神，忠诚与力量的化身，被认为是中国《西游记》孙悟空的原型之一。

### 《摩诃婆罗多》

《摩诃婆罗多》是世界最长的史诗（约10万颂），核心故事是般度族与俱卢族争夺王位的"俱卢之野"大战。

其中最著名的是第六篇《薄伽梵歌》——黑天在战前向阿周那讲述"业道""智道""信道"，阐明"无执而行"的哲学。这段对话被奉为印度教核心经典。

## 五、印度神话的影响

1. 东南亚：印度神话随印度教/佛教传播，深刻影响柬埔寨、印尼、泰国——吴哥窟的主题就是《摩诃婆罗多》和《罗摩衍那》。
2. 瑜伽与冥想：印度神话的苦行观念演化为今天全球流行的瑜伽。
3. 流行文化：《少年派的奇幻漂流》派的名称Pi就来自"毗湿奴"的"P"，整部电影充满印度教隐喻。
4. 比较：哈奴曼→孙悟空，罗摩流放→奥德修斯归途，三相神→基督教三位一体，都能看到跨文化的共鸣。

## 总结

印度神话的独特之处，在于它把"神"和"哲学"融为一体——三相神不只是创世—维持—毁灭的分工，更对应"存在—维持—非存在"的形而上学。

读印度神话最震撼的，是看到一个文明用几千年时间，把神话、哲学、宗教、社会制度层层叠加，最终形成一个可以容纳无数神祇又指向"梵"的庞大体系。它不要求你信某一位神，而是让你看到"所有神都是同一个梵的不同面向"——这种"多即一"的智慧，让印度神话在世界神话中独树一帜。
