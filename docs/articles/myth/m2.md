# 苏美尔神话：人类最古老的神话体系

苏美尔人在公元前3500年左右创立了人类已知最早的城市文明，他们也留下了人类最古老的神话体系。苏美尔神话比希腊神话早了近两千年，比《圣经》早了三千多年，是整个西亚神话传统的源头——后来的巴比伦神话、亚述神话、赫梯神话，乃至希伯来《圣经》中的许多故事，都能在这里找到原型。

## 一、苏美尔神话的总体特征

与希腊神话的"神人同形同性"不同，苏美尔神话有三个鲜明特点：

1. **神权与人权高度结合**：苏美尔城邦被视为"神的封地"，每个城邦都有自己的守护神，国王是神在人间的代理。
2. **神祇分工明确**：每一位神负责一项具体职能——天、地、空气、水、月、太阳、农业、战争，几乎对应了古代社会生活的所有方面。
3. **人是神的附庸**：苏美尔神话认为人是神用泥土捏出来为神服务的，人的存在意义就是供养神、服从神。这种观念深刻影响了后来的西亚宗教。

## 二、苏美尔神祇体系

苏美尔神话没有像希腊《神谱》那样有一个统一的成文版本，但从出土的楔形文字泥板中可以还原出一个相对清晰的神系。

### 1. 原始神：安与启

- **安**（An）：天神，众神之父，苏美尔神话中最高贵的神。他是天空的化身，象征着宇宙的最高秩序。安虽然地位最高，但在神话中很少直接行动，他把统治世界的权力交给了儿子恩利尔。
- **启**（Ki）：地神，大地的化身。安与启结合，生出了空气之神恩利尔。

"安"在苏美尔语中就是"天"的意思，"启"就是"地"的意思。这对天地夫妻的设定，与后来希腊神话中乌拉诺斯（天）与盖亚（地）的关系极为相似——很可能是同一原始宇宙观在不同文明中的演变。

### 2. 恩利尔：真正的众神之王

**恩利尔**（Enlil）是安与启的儿子，空气与风暴之神，也是苏美尔神话中**实际的众神之王**。

恩利尔的地位非常特殊：他虽然是安的儿子，但在众神之中拥有最高的决策权。传说安将"天命石板"（决定万物命运的神器）交给了恩利尔，从此恩利尔成为宇宙秩序的实际维护者。

恩利尔的妻子是**宁利勒**（Ninlil），空气女神。他们的结合生下了月神南纳。

恩利尔最著名的事迹是**发动大洪水**。因为人类的喧闹打扰了众神的安眠，恩利尔决定用洪水消灭人类。这个故事后来被编入《吉尔伽美什史诗》，再后来又成为《圣经》中诺亚方舟故事的原型。

### 3. 恩基：水与智慧之神

**恩基**（Enki，阿卡德语称埃阿Ea）是淡水与智慧之神，安的另一个儿子。

恩基是苏美尔神话中最"人性化"的神：他聪明、幽默、爱恶作剧，也常常帮助人类。在大洪水的故事里，正是恩基违背了恩利尔的旨意，悄悄提醒义人乌特纳皮什提姆建造方舟，才使得人类没有被彻底灭绝。

恩基还是人类的创造者之一。传说他用泥土混合神的血液，捏出了最初的人类，让他们为众神服务。

**拓展**：恩基的形象很容易让人联想到希腊神话中的普罗米修斯——同样是帮助人类的神，同样因为违抗神王的旨意而受到惩罚。这两个形象跨越两千年时空，却有着惊人的相似性。

### 4. 南纳：月神

**南纳**（Nanna，阿卡德语称辛Sin）是月亮之神，恩利尔与宁利勒之子。

需要说明的是，南纳是**男神**而非女神。他被描绘为一位戴着月牙冠、驾着月船在夜空中航行的神祇。苏美尔人认为月亮掌握着时间的节律，因此南纳也是历法之神。

南纳最重要的孩子是**伊什塔尔**（Ishtar，苏美尔语称伊南娜Inanna）——金星女神，掌管爱情、生育与战争。伊什塔尔是苏美尔神话中最具个性的女神，她的形象后来演变为希腊神话中的阿佛洛狄忒。

### 5. 伊什塔尔：爱与战争女神

**伊什塔尔**（伊南娜）是苏美尔神话中最复杂、最有魅力的女神。她既是爱情与生育女神，又是战争女神，掌管金星。

她最著名的故事是**下冥府**。为了救出爱人杜姆兹（Tammuz），伊什塔尔冒险进入冥府，在通过七道门时被剥去了所有衣物和神性，最终被冥府女王埃列什基伽勒杀死。后来众神用计让伊什塔尔复活，但她必须每年有半年时间待在冥府——这就是四季更替的由来（类似希腊神话中珀耳塞福涅的故事）。

## 三、创世与洪水

### 创世

苏美尔创世神话散见于多块泥板，没有统一的文本。大致的创世过程是：

1. 最初有原始淡水神**阿普苏**（Apsu）和咸水女神**提亚玛特**（Tiamat）。
2. 两大水域交合，生出了众神。
3. 众神的喧闹惹怒了阿普苏，他想要消灭众神。
4. 恩基设计杀死了阿普苏。
5. 提亚玛特为夫报仇，创造了怪物军团。
6. 最终新一代神战胜了提亚玛特，用她的身体创造了天地。

这个创世框架后来被巴比伦人完整继承，写成了著名的创世史诗《恩怒玛艾里施》。

### 大洪水

苏美尔洪水故事是人类已知最早的洪水传说，核心情节：

1. 众神决定用洪水消灭人类，因为人类太吵闹。
2. 水神恩基不忍心人类灭亡，偷偷告诉义人**乌特纳皮什提姆**（Utnapishtim）建造一艘大船。
3. 洪水淹没大地，只有乌特纳皮什提姆一家和各种动物幸存。
4. 洪水退去后，乌特纳皮什提姆放出鸽子探知陆地。
5. 众神后悔，赐予乌特纳皮什提姆永生。

这个故事后来被编入《吉尔伽美什史诗》，再后来演变为《圣经》中的诺亚方舟。**对比来看，三个故事的核心结构几乎完全一致**——这证明了苏美尔神话对整个西亚文明的深远影响。

## 四、吉尔伽美什史诗

**《吉尔伽美什史诗》**是人类已知最早的史诗，比荷马史诗早了一千多年。

### 故事梗概

**吉尔伽美什**是乌鲁克城邦的国王，三分之二是神、三分之一是人。他强大但残暴，压迫乌鲁克人民。众神为了制衡他，创造了野人**恩奇都**（Enkidu）。

吉尔伽美什与恩奇都相遇后打成平手，反而成为挚友。两人一起冒险——杀死杉林守护者洪巴巴、杀死天牛。

但恩奇都后来被众神惩罚而死。吉尔伽美什无法接受好友的死亡，开始惧怕死亡，踏上了寻找永生的旅程。

他找到了大洪水的幸存者乌特纳皮什提姆，乌特纳皮什提姆告诉他：永生无法获得，但可以通过留下美名来获得"另一种永生"。

最终吉尔伽美什回到乌鲁克，虽然没有获得永生，但他通过建立伟大的城邦和功业，让自己的名字永垂不朽。

### 史诗的意义

《吉尔伽美什史诗》探讨了一个永恒的主题：**人终有一死，那么生命的意义是什么？**

吉尔伽美什从一个残暴的暴君，成长为一个懂得珍惜友谊、接受死亡的成熟君王。这个转变过程，是人类文学中最早的"成长叙事"。

**拓展**：吉尔伽美什的故事与后来希腊英雄有很多相似之处——都是半神英雄、都有一个挚友（类似阿喀琉斯与帕特罗克洛斯）、都在追寻不朽。这些相似性暗示了西亚神话对希腊神话的深刻影响。

## 五、巴比伦传承：《恩怒玛艾里施》与马尔杜克

笔记中提到的创世史诗**《恩怒玛艾里施》**（Enuma Elish，意为"当诸天之上"），实际上是**巴比伦人**继承并改写苏美尔神话后的作品，而不是苏美尔人原创。

这部史诗的主角是**马尔杜克**（Marduk，笔记中写作"马都克"），他是巴比伦城邦的守护神。

故事核心：当提亚玛特为夫报仇、率领怪物军团进攻众神时，年轻的马尔杜克挺身而出，斩杀了提亚玛特，并用她的身体创造了天地。作为回报，众神推举马尔杜克为众神之长。

这个故事的政治含义很明显：巴比伦城邦的守护神马尔杜克成为众神之王，反映了巴比伦在政治上取代苏美尔成为西亚霸主的历史事实。

**对比苏美尔与巴比伦**：
- 苏美尔神话中，众神之王是恩利尔；
- 巴比伦神话中，众神之王变成了马尔杜克。

这体现了古代西亚"神权随政权转移"的规律——哪个城邦称霸，它的守护神就成为众神之首。

## 六、苏美尔神话的影响

苏美尔神话虽然随着苏美尔文明的消亡而中断，但它的影响通过巴比伦人、亚述人、赫梯人、腓尼基人一路传承，最终渗透到西方文明的根基之中。

几个重要的传承链条：

1. **洪水传说**：苏美尔乌特纳皮什提姆 → 《吉尔伽美什史诗》 → 《圣经》诺亚方舟 → 西方文学中无数"洪水"母题。
2. **创世框架**：苏美尔阿普苏与提亚玛特 → 巴比伦《恩怒玛艾里施》 → 希腊《神谱》中乌拉诺斯与盖亚 → 基督教《创世记》。
3. **英雄史诗**：吉尔伽美什与恩奇都 → 希腊阿喀琉斯与帕特罗克洛斯 → 中世纪骑士文学 → 现代冒险故事。
4. **女神下冥府**：伊什塔尔下冥府 → 希腊珀耳塞福涅神话 → 季节更替的神话解释。

## 总结

苏美尔神话是人类文明最早的精神产物之一。它不像希腊神话那样充满戏剧冲突和人性光辉，也不像《圣经》那样有严密的神学体系，但它的**原始性**恰恰是它最珍贵的地方——我们可以从中看到人类最初是如何理解世界、理解自身、理解死亡的。

读苏美尔神话最大的震撼，是**感受到一种跨越五千年的共鸣**。当我们读到吉尔伽美什面对恩奇都之死时的恐惧与绝望，我们会发现：五千年前的人与今天的我们，面对死亡时有着完全一样的感受。这种共鸣，就是神话跨越时空的力量。

苏美尔神话是整个西方神话传统的源头，理解了它，再去读希腊神话、读《圣经》、读现代文学，都会有更深刻的理解。
