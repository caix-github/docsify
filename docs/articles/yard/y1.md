# 大院

我是生活在大院的，准确来说是生活在一大院的。因为我家门口外就有三个大院。它们紧挨着，十分宽敞。站在一大院中央，目光往另外两大院一扫，都能尽收眼底。每天日初，阳光浩浩荡荡洒落在大院那一块块正方形的混凝土地上，晨光杲杲，像一板刚出炉的白豆腐，热气腾腾。大院一隅，有几根用竹竿搭好的晾衣架，每当上午一到，过几条巷子的老婶们便会拎着一桶湿漉漉的衣服出来晾晒。除此之外，大院便略显得空荡，却不显得荒莽。从大院抬头一望，发现此刻湛蓝的天空，带些云卷云舒，正与静仰的大院面面相觑。

大院的拐角处，还固定着一根长竹竿，顶端用铁丝绳绑着一个大喇叭。平常日子它默默不吭声，每当村委有公告，这喇叭便开始叽叽喳喳地响。这一响便会引起左邻右里的关注，家里端着杯喝水的，看电视的，忙活的纷纷放下手中活，静静聆听广播带来的消息，有的走到巷头与大院交汇的地方，在那里听消息再清晰不过。这消息一播放完，大家伙便走街串巷四处闲谈，议论纷纷，它化作了一种消遣的绳子，拉紧着左邻右里彼此嘘寒问暖的关系。

夜深人静时，大院上空是一个皎月高挂，斗转星移的夜幕。静静仰望夜空，在清风徐来的加持下，那种静谧又心旷神怡的感觉迎面而来。时有低飞的飞机掠过，它展开着一对时而闪烁的翅膀，紧接着耳边便萦绕着一阵轰鸣声而过。公厅前的路灯在大院的一隅，驱散了黑暗，撒下一片白霜，与白月光相互呼应，像是月亮给路灯捎了书信。虽然这光显得微弱，却依旧能提供一点视觉上的指引。那灯罩甚至还能给不知名的昆虫提供照明和栖息，它们不知疲倦地在灯泡周围扑飞着，飞累了就停留在上面片刻。
