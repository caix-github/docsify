# 大院－老热

老热，那是老家话直译过来的，也叫营大老爷，可以理解为类似粤西地区的年例。是广泛流传于福建省和广东海陆丰地区和潮汕地区及其周边地区的乡村和城市社区中的一种传统民俗祭祀活动，祈求风调雨顺，全村平安。村里头频繁的每三四年轮流一次，久的每七八年轮一次，比奥运会还久。轮到的那村，每家每户会进行捐钱，数目有多有少，量力而行。有的地方如果数目多的那户会送一面锦旗或者其他礼品，刻在石碑的最前头，髹上金漆，排在最醒目的位置。

在筹办的前几天，村里头便会开始在道路两旁插彩旗，布线挂上红灯笼。村门口搭起竹制龙门，门眉有着镂空浮雕，双龙戏珠，寓意跃龙门。走进龙门往上望，龙门后用两三米细绳五彩缤纷的倒三角彩旗，队形呈现散发式。一阵风吹来，它们便在风中尽情地飞舞，紧接着便是一长串圆嘟嘟的红灯笼，灯衣上绘制着喜庆的图案，每个灯笼体内都有一颗灵魂式灯泡，透过通透的灯衣隐约可见，像颗有生命力的心脏，灯体下悬挂的灯穗也跟着风自由摆动。道路被两边的灯笼装扮得严严实实，把喜庆的气氛聚拢得更加浓烈。除了灯笼，郁郁葱葱的草丛边也错落有致地插上用竹棍穿好的彩旗。它们用路标式默默地指引着来自四面八方慕名而来的游客。随着灯笼的指引来到大院，白天的大院此刻正处于休憩状态，远远望去，只有几排门可罗雀的摊位。它一片敞亮，晨光杲杲，有些沉寂，像一个赶工的夜班人，白天呼呼大睡，只为黑夜苏醒。

夜幕降临前这里早已灯火通明，龙门上的灯，灯笼的灯，路标的彩灯等万灯众亮时，光彩夺目。人群如织，在阡陌交通中缓缓流动。街道两旁便有推着自行车卖气球的，摆地摊卖腌制水果的，三轮车上卖奶茶的，扛着大棒卖冰糖葫芦的，挑着扁担篮筐卖糖葱薄饼的，吆喝声四起，热闹无比。沿着街道通向大院，大院此刻被几排摊位占据得满满当当，香味扑鼻的烧烤烟在院中袅袅升起，正挑逗着每一位寻觅而来的老饕的味蕾。地摊中的还有几家套圈的，一家前前后后摆满了瓷器，从小到大，从掉落在身旁的圈圈来看，也许已经经历了无数次擦肩而过。另外还有套小动物的，长方形矮小的铁笼关着仓鼠的，兔子的，荷兰猪的，有的活蹦乱跳，有的静悄栖息。还有用塑料制的长盒装着金鱼的，突兀的眼睛正在好奇地扫视着四周的环境。

此刻的大院，除了热闹的地摊，公厅也灯光璀璨，一道拱形龙门，门梁，周边墙壁张灯结彩，一闪一闪。正门口搭着祭祀台，台前点燃着三柱朝天巨香，烟火通向了高空弥漫的夜色，仿佛水乳交融，瞧不出模样。从公厅外头往里头走，两边的架台上放置着五彩十色的水景灯，低涌的流水托举着一颗晶莹剔透的水晶球，水晶球在水流的涌动中缓缓转动，水雾弥漫。每个水景灯布置的场景都各式各样。有龙飞凤翥，蟠桃祝寿，八仙过海等美好寓意的主题，缥缈的高山流水，憨态可掬的人物，栩栩如生的小动物。远望便是一幅栩栩如生的写画，人烟稀少时贴近水晶灯能细听到一种静谧的水潺声。公厅正前方便是三樽庄严肃穆的神像，中央摆放着六张大方桌，桌上精摆着满满当当的祭品，侧旁还有猪羊各一只。从公厅里头往外看，夜晚的大院便在那个灯火阑珊的边框中。喜庆，热闹，灯火填满了整个宽敞大院。

热闹当天，一大早便能不见其场面，远闻其声。属于早晨的寂静此刻像个镜子般被打得支离破碎。喇叭声，锣鼓声，鞭炮声交织着从远处传来耳际。匆匆洗漱完跑出门看，发现此刻的主路已万人空巷，纵横交错的巷子里也熙熙攘攘。去早的在大院里挑位置坐前排，晚来的只能在人头攒动的观众队伍中寻找观缝，机灵点的从家里拎来几张凳子，选个视角佳的位置踩着凳子观看。远瞧几只醒狮正在大院一隅搭建着梅花桩上蹦跶，侧旁律动的鼓声传遍四面八方。梅花桩下的狮子一会睁眼，一会洗须，舔毛，生龙活虎在大院舞动着。这醒狮，历史上据说是从唐代狮子舞演变而来，五代十国后，随着移民来到岭南，后来佛山南海发展壮大。醒狮原名为瑞狮，意为吉祥如意，是佛山民间的庆祝方式。直到鸦片战争的战火蔓延到南方，因为瑞字方言谐音睡，具有民族忧患感的佛山人便将其改为醒狮。这成为了扬民族之威、立中国之魂的重要仪式。

与此同时，其他表演正在紧锣密鼓地进行着，巡游队伍此时此刻在旁边大院井然有序地排好队伍。他们这几天不辞劳苦，在当天凌晨五六点便须赶往村里头临时搭建好的化妆区化好妆容。化好妆容后，再回去着装。有的小孩子此刻在家长怀里呼呼大睡，有的估计睡得早面容看起来精神抖擞。三声地动山摇的鞭炮声过后，五彩的烟花一飞冲天，几长串的鞭炮铺天盖地响起，震耳欲聋，浩荡的队伍像蜿蜒的巨龙便开始游动起来。首当其冲的是一位将军骑着一匹战马，看起来高大威武，身后跟随着几个兵将。其次是祥瑞的龙飞凤舞，几只醒狮在威振的鼓声中舞动，紧接着还有两支闻名遐迩的英歌舞，其中一支是充满青春活力的少年英歌舞，一对对英歌槌，舞蹈时在手中翻转，舞蹈动作以南派武功为基础，刚健有力。悦耳的打击乐夹带慷慨激昂的吆喝声。英歌舞是闽南地区一种糅合南派武术、戏剧地方艺术的民间舞蹈， 歌颂的是扶正压邪、团结战斗和勇敢拼搏的英雄气概。随后便是浩浩荡荡的巡游队伍，前头是旗手，长者队，几个青壮年抬着供奉老爷神像的轿子，中间有标旗、彩旗、花篮，最后是悦耳动听的笛套音乐和锣声噌吰的潮州大锣鼓。队伍所到之处前，便有一长串的鞭炮为其引路，附近的街坊也会闻其鞭炮声前来观看。那红色的鞭炮渣，像给前来的队伍铺上了一层红毯。队伍周边有着维序人员，他们胸前佩戴着红花徽章，手持一根红白相间的长竹竿，为前行的队伍腾出一条畅通无阻的前路。巡游队伍走遍大街小巷，巡游人员会有家人作为后勤人员保持补给。队伍需要巡游三天，第一天代表老爷出宫，第二天代表老爷巡游，第三天代表老爷回宫。第二天的巡游最是热闹，通常会有前头说的醒狮和英歌舞等表演队伍，前后两天主要是巡游队伍的游动。

游神那几晚，大院也热闹非凡，大院的拐角处搭建着大戏台，戏台基台用钢架以榫卯式结构组装而成，戏台上的主要用竹竿搭建，棚纸搭建天幕。戏台中央有多层幕布，左右两侧也有张帘布，方便场景切换。戏台两边主要是戏乐人员演奏的区域，舞台后方则是戏员的准备区域。个别熊孩子喜欢趴在戏台边，时不时掀起帘布观看里头的情况。老人家们早早便在舞台中选座坐下，有的跟着家人们，有的跟着街坊邻居，有的带着小孩前来观看。当时刻已到，悬挂的荧屏字幕亮起，一出好戏开场，帘布缓缓拉开，悠扬婉转戏乐声响起，台上表演精湛，台下座无虚席。凳子不够坐的，自己从家里头拎椅子来。

戏台外边，让人垂涎欲滴的小吃摊，让人心生玩趣的玩乐摊，让人眼花缭乱，五光十色的公厅。此刻的大院，让人流连忘返。
