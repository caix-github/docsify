# 大院－风筝

夏秋季里，大院时常有浩浩荡荡的大风来撒野。有时在屋里呆闷了，便喜欢呼朋引伴号集大家一起放风筝。浮想着跟随风筝在宽敞的大院里，那种感觉真令人惬意。路边的小卖部基本都有售卖风筝，形态各异，最常见有蝴蝶状、猫头鹰状、蜻蜓状等。那时候对于我们来说，除了零花钱不多的原因外，主要也是想自己做，像是做一门手工艺品。制作风筝的材料也不难找，从家里搜刮而来的一沓旧报纸，找张废草席抽出数根竹篾来做风筝的骨架，带上一瓶贴春联用的糨糊，一把剪刀和胶带，把材料拎到大院一处地，大家伙一起开工。

首先把竹篾折成几段，搁置平地上，摆好风筝合理的骨架结构。确定无误后，剪上几段胶纸并贴在骨架交叉位置进行固定。骨架成型后，可以检查下关键部位是否牢固，否则后续放飞的时候容易散架。然后便可以给风筝贴上风衣，取旧报纸修剪好风筝的外形，用糨糊进行贴合，剪上两条风筝尾粘牢在风筝主体边上，再用胶纸在再贴牢关键部位。最后，买上一卷风筝线，在风筝骨架中央进行系牢，并多缠上几圈。拴紧好绳结，一个风筝便大功告成。

有了风筝后，便开始试飞行。需要两人配合，一人高高托举好风筝，另一个拉着松好的一段风筝线往前跑，高举的风筝在线的牵拉下，瞬间便奋起直追。那两条尾巴像柳枝一样在风中自由地飘舞起来，带着窸窸窣窣的声响。它萦绕在耳边，如果出现转圈挣扎的现象，那需要检查下问题。一切顺利的话风筝便会一飞冲天，越飞越高。像起跑的飞机，在奔跑中慢慢被气流托起。它又像一只跃跃欲试的稚鸟，那种成功翱翔在空中的喜悦也降落在你身上。

片刻间，当许多风筝像鸟一样在空中翱翔，它们闯进了大院那片蔚蓝得单调的天空里，时高时低。仰望着上空，带来了一种动静结合的赏心悦目。此刻的天空就像一幅栩栩如生的群鸟竞飞图，它悬挂在上空，正倒映在大院上。
