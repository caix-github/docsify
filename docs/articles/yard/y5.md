# 大院－狩猎游戏

夜幕下的大院，除了有白花花的路灯光，还有凉爽的晚间清风。有时晚间闲暇时刻，拉上邻里的阿依阿胜，加上在大院游玩的其他小伙伴，玩起一个狩猎游戏，游戏规则是先选出一个老鹰角色，其他人则为野兔角色。再猜拳决定野兔的出发顺序，老鹰在狩猎点蓄势待发。每一轮，野兔出逃，老鹰在狩猎点出击。如果野兔在外兜完一圈后成功逃过一劫回来，继续下一轮追击，如果老鹰狩猎成功，则互换角色。这个游戏对于跑得快的人来说极具优势。

游戏开始前，我们在大院的公厅前，选了一块长石阶作为大本营。那天依稀记得选出了一只老弱的老鹰，仿佛已过了耄耋之年。平常我们几个中属阿胜是跑得最慢的，在奔跑过程中身体还带些踉跄。最后一个是隔壁巷的小不点，由于他比较矮小，我们一时兴起便起了此名。只见小不点以迅雷不及掩耳之势向大院被暗夜沉浸的远方飞奔。那只老鹰被狠狠地甩在身后，兜转了一圈，在暗亮的交界处逐渐放大他的身影，转眼间，他已回到野兔的大本营。而老鹰在远处弓背残喘着，最后彳亍回来。后来我们也说这小不点未来不去当个运动员可惜了，至于后续有否就不得而知了。

几轮游侠下来，大家都轮番进行了几圈夜跑。在夜黑风高的大院里，酣畅淋漓地解放属于孩童的天性。那晚，本该被夜寂笼罩的大院，被那一声声尖叫夹杂着欢笑声所打破
