# 大院-遥控汽车

十几岁的一天晚上，大舅下班后拎着两个黑色塑料长袋来到我家。我们兄弟俩解开黑色塑料一看，原来是两辆遥控汽车，望着那个华丽包装的遥控汽车，一时欣喜若狂。我首选了一个大盒子的汽车，拆开包装，一辆黑色SUV式遥控汽车，它有两层塑料壳，一个贴合车底盘零部件的内壳，外头加一个显得高大尚的黑色外壳。它搭配了一个类似大哥大与手枪结合版的遥控器，扣动扳机可以实现汽车的前进和后退，遥控中间有个大旋钮，左右扭动可以实现车子的方向，左上角搭配着一根伸缩式的天线。老弟那辆是一辆红色的小型跑车，搭配一个手柄式遥控器。那两辆车，不知不觉中也融进了我们童年的生活。

每当晚饭后，兄弟俩便到大院里头遛汽车。把两辆车放到踏入大院的台阶作为起跑线，自定一条笔直的赛道，看谁的车先跑到大院另一头的终点。汽车马达发出的嗡嗡声顿时划破了笼罩在大院的寂静，像两只小动物猛地一瞬间扎进夜色渐浓的大院里。跑完比赛后，便在大院里头各自遛车。在大院的一边自由驰骋到另一边，遇到犄角旮旯转个弯或调个头。遛得无聊时，去捡些石头错落有致地摆好，充当汽车的障碍物，让车子突破这层堆障碍物，顺利地驶出。有时候把车开到一段坡，让车子在坡路那里上下跑动，那是一段坑坑洼洼的坡路，车子在上面跌宕起伏地跑动，模拟出一种越野的感觉，就差自己坐进那驾驶室，一种危险带来的刺激，一种未知引发的好奇，让人像爱上辣椒般欲罢不能。

有时候把车拿到大院石栏边的水沟，让车沿着水沟边向前行驶，营造一种莫名车子在河边奔驰的感觉。水沟里的水也缓缓向前，时而水面上有落叶或者纸片像小船徐徐向前，跟奔驰的车子比起来，它们仿佛像个耄耋之年的老人，正在水面上踽踽独行。有时候又想着这车子的体型能再大点就好了，坐在上面，让它带着我们在院子里四处兜风，再兜上白天金灿的阳光和松软的卷云。
