# 大院－蜗牛

夏季的大院，那是一个凉快的地方。待在房屋里即使有风扇呼呼地吹着，估计也比不上站在院里享受晚间清风。尤其是行至院中央，展开双手，感受风缓缓从衣袖穿过，从身体的犄角旮旯穿过，从头发的缝间穿过。一种来自大自然的抚摸，让人神清气。大院中央有一个公厅，从门口望进，厅里悬挂一块明镜牌匾，左右两摆放着两排红漆椅。那是大院的公议厅，平常有什么要紧事，那厅里便会召集村里许多德高望重的老人在此商议。不少重大决策便从厅里传出来的。

不过我们对厅门外两侧的墙角更熟悉。那有陪伴我们夏天的伙伴，蜗牛。它通透的螺旋外壳，两根探头探脑细萌还带些黏液的触角，加上那在地面蠕动叶子似的裙边。在公厅粗糙的墙角落边一搜罗，有时可以看见独自前行的，有时可以看见成双成对的，运气好些可以看见成群结队的。看到这不禁想起一首童歌，“阿门阿前一棵葡萄树，阿嫩阿嫩绿的刚发芽。蜗牛背着那重重的壳呀，一步一步地往上爬。”，等它接近葡萄时，刚好成熟了，一想起真是稚趣横生。它重重的壳，好奇心都会让人不假思索，这壳到底装着什么呢？那时候一种天马行空的想法便是它是拖家带口的，装着整个家的行当，包括家具，电器，食物等，像一个现代版的货拉拉。

几个人蹲在那里，默默地看着它们缓慢地蠕动，看得出神，耐不住的小伙伴就会用手去扒拉它。一经外界的影响，它们警惕地缩进那个神秘的壳里，一动不动，远看还以为是一颗小石子，以此来逃过一场凶险。有一天晚上，我们发现有几个小伙伴手拿着一个个矿泉水瓶，那瓶子被剪刀从瓶颈剪开了一个大口，有的瓶子里头已放进了好几只蜗牛，它们都蜷缩在壳里，当瓶子晃动时，只留下窸窸窣窣的声响。转身一看，一个小伙子的手背上有只蜗牛正在蠕动，蠕动的同时边分泌的一种黏液。我们凑近鼻子过去一闻，一股淡淡的腥味，那味几乎可以忽略不计。那时候我们把蜗牛叫俺罗。传有一个有趣的传闻说，如果它缩进壳里时，面对它的小壳口连续呼唤三声俺罗，它便会慢慢弹出头来了。至于大家有没有这么召唤过，也就不得而知了，反正我是没有。
