# 隋唐五代 · 盛世的成熟与裂变

> "忆昔开元全盛日，小邑犹藏万家室。" ——杜甫《忆昔》

581 年隋代北周，589 年灭陈统一，再到 960 年北宋建立，共 379 年。这是中国帝制时代的"黄金期"——**科举、三省六部、贞观开元、诗与佛**都是这一阶段的标签，是后世所有改革者都想"回到"的理想年代。

## 一、隋朝（581—618）

### 1. 隋文帝杨坚：制度奠基者

- 北周外戚杨坚 581 年代周建隋，589 年南下灭陈，结束 369 年分裂。
- **开皇之治**：勤政节俭、轻徭薄赋、编订《开皇律》（废除孥戮、连坐酷刑）。
- 制度：
  - **三省六部制**：内史（中书）、门下、尚书三省；尚书下设吏户礼兵刑工六部，奠定后世官制框架。
  - **科举制**（587 起开科举人）：以考试代替门第，打通社会上升通道。
  - **均田制与租庸调**：国家授田，按丁征调（租=粮、庸=布、调=丝麻）。
  - **大运河**：605—610 年开凿，贯通海河、黄河、淮河、长江、钱塘江五大水系，成为中国经济大动脉。

### 2. 隋炀帝杨广：争议巨大的"亡国之君"

- 604 年弑父即位（史载如此，争议大）。
- 大业年间建东都洛阳、修大运河、三征高句丽、巡江都——工程规模空前。
- 滥用民力导致民变四起：王薄唱《无向辽东浪死歌》、瓦岗军、窦建德、杜伏威等起义。
- 618 年炀帝在江都被宇文化及缢杀，隋亡。
- **后世重评**：大运河之功不可没，但急功近利、不顾民力是其致命之失。司马光评："炀帝以亿万劳之力，博一身之乐。"

## 二、唐朝（618—907）

### 1. 建国与玄武门之变

- 李渊（唐高祖）617 年太原起兵，618 年称帝建唐，定都长安。
- 秦王李世民战功显赫，626 年发动**玄武门之变**，杀兄建成、弟元吉，迫父禅位，是为唐太宗。
- 这一"以弟弑兄、以臣逼君"的政变，在儒家伦理上是污点，但其带来的"贞观之治"使后世史家多所回护。

### 2. 贞观之治（627—649）

唐太宗李世民在位 23 年，被誉为中国帝制史上的明君典范。

- **纳谏**：魏征直谏 200 余事，太宗"以铜为镜，可以正衣冠……以史为镜，可以知兴替"。
- **任人**：房玄龄、杜如晦（"房谋杜断"）；科举扩招；胡汉并用，阿史那社尔、契苾何力等胡将任用不疑。
- **制度**：完善三省六部制；修订《唐律疏议》——中国律法的集大成者，影响日本、朝鲜、越南律制。
- **军事**：李靖灭东突厥（630），擒颉利可汗；之后灭吐谷浑、高昌、薛延陀；设安西、北庭都护府控西域。
- **文化**："**天可汗**"尊号显示唐是当时东亚的国际共主；玄奘西行取经（627—645）写成《大唐西域记》；文成公主入藏（641），与松赞干布和亲。

### 3. 武周（690—705）

- 武则天是中国历史上唯一被广泛承认的**女皇帝**。
- 出身关陇贵族，初为太宗才人，后为高宗皇后，660 起临朝称制。
- 690 年改国号为"周"，定都洛阳。
- 政绩：开殿试、扩科举、破门第、用酷吏（来俊臣、周兴）压制反对派；知人善任（狄仁杰、张柬之、姚崇）。
- 705 年宰相张柬之等发动"神龙革命"，迫武后退位，中宗复辟。
- **争议**：传统史家多负面，但近世评价转正——其手腕强、政绩实，承前启后到开元。

### 4. 开元盛世（713—741）

- 唐玄宗李隆基前期的 29 年，唐朝臻于鼎盛。
- 姚崇、宋璟、张九龄三相依次执政，改革吏治、抑制宗室、清查户口、整顿漕运。
- 国力：人口达 8000 万（一说 7000 万），疆域东至大海、西抵咸海、南到越南、北达贝加尔湖。
- 文化：李白、杜甫登场；王维、孟浩然田园山水诗；吴道子绘画；颜真卿书法（稍后）；张旭、怀素草书；公孙大娘剑舞——这是一个"诗与剑"齐飞的年代。
- 国际：长安是当时世界最大都市，胡商、波斯王、日本遣唐使汇聚，景教、祆教、摩尼教、伊斯兰教并存。

### 5. 安史之乱（755—763）与中晚唐

#### 叛乱背景

- 玄宗后期怠政，宠杨贵妃，委政李林甫、杨国忠。
- **节度使权重**：边防十节度使拥兵 49 万，安禄山一人兼三镇节度使，掌全国精兵三分之一。
- 755 年安禄山以"讨杨国忠"为名于范阳起兵，南下陷洛阳，破潼关。
- 756 长安陷，玄宗奔蜀，马嵬坡兵变杨贵妃缢死。
- 太子李亨在灵武即位，是为肃宗。

#### 平叛与后续

- 郭子仪、李光弼借回纥兵平叛。
- 763 年史朝义死，叛乱终。前后 8 年。
- **影响**：唐从鼎盛跌入中晚唐，藩镇割据、宦官专权、朋党之争（牛李党争）三大痼疾贯穿。

#### 中晚唐改革

- **两税法**（780，杨炎）：以资产而非人头计税，简化税制，是税制史上一大革命。
- **元和中兴**（806—820）：宪宗削弱藩镇，一度统一政令。
- **会昌灭佛**（845）：武宗毁佛寺 4600 余所、收僧尼 26 万归俗，是历史上"三武一宗"灭佛之一。

### 6. 唐末大乱与灭亡

- 875 年**黄巢起义**爆发，转战大江南北，880 攻破长安，建国"齐"。
- 黄巢部将朱温降唐，平叛有功，907 年废唐哀帝建后梁，唐亡。
- 中国进入五代十国。

## 三、五代十国（907—960）

### 1. 五代（北方）

| 朝代 | 起止 | 民族 | 都城 |
| ---- | ---- | ---- | ---- |
| 后梁 | 907—923 | 汉朱温 | 汴（开封） |
| 后唐 | 923—936 | 鲜卑沙陀 | 洛阳 |
| 后晋 | 936—947 | 鲜卑沙陀 | 汴 |
| 后汉 | 947—950 | 鲜卑沙陀 | 汴 |
| 后周 | 951—960 | 汉郭威 | 汴 |

### 2. 十国（南方）

南方九国加北方北汉，合称"十国"：吴、南唐、吴越、闽、楚、南汉、前蜀、后蜀、荆南、北汉。

- **南唐**：李昪、李璟、李煜三代，文化繁盛。李煜是"千古词帝"，亡国后词境登峰。
- **吴越**：钱镠保境安民，开发杭州、修海塘，"保境安民、善事中国"成为立国策。
- **后周**：世宗柴荣一代雄主，奈何 959 年北伐契丹时病逝，留下幼帝，被赵匡胤陈桥兵变取代。

### 3. 时代特征

- 武将专权、皇位篡弑频繁（"天子宁有种耶？兵强马壮者为之尔！"）。
- 但南方相对安定，经济重心南移加速。
- **大运河**已成经济命脉，开封因漕运便利逐渐取代长安成为新中心。

## 四、文化与制度：盛唐的世界性贡献

### 1. 制度

| 制度 | 内容 |
| ---- | ---- |
| 三省六部 | 中书起草、门下审核、尚书执行；六部为吏户礼兵刑工 |
| 科举 | 常科、制科；秀才、明经、进士诸科，进士最贵 |
| 律法 | 《唐律疏议》→《唐六典》→《大宝令》（日本沿用） |
| 府兵制 | 兵农合一，到武周时崩坏，募兵制起而代之 |
| 两税法 | 780 杨炎改按丁征税为按资产征税 |
| 节度使 | 边防军政合一，安史之乱后割据中央 |

### 2. 文化

| 领域 | 代表 | 成就 |
| ---- | ---- | ---- |
| 诗歌 | 李白、杜甫、王维、白居易 | 唐诗是中国诗歌巅峰 |
| 散文 | 韩愈、柳宗元 | 古文运动，反骈重散 |
| 词 | 温庭筠、李煜 | 词的早期发展 |
| 书法 | 颜真卿、柳公权、怀素 | 颜筋柳骨、狂草双绝 |
| 绘画 | 吴道子、阎立本、王维 | "画圣"吴道子 |
| 史学 | 刘知几《史通》、杜佑《通典》 | 中国史学批评与典制体 |
| 宗教 | 玄奘、鉴真、慧能 | 禅宗汉化，佛教鼎盛 |
| 科技 | 僧一行测子午线、雕版印刷萌芽 | 印刷术起源 |

### 3. 国际化

- 长安人口百万，胡商数万。
- 日本遣唐使 19 次，吉备真备、阿倍仲麻吕留唐做官。
- 阿拉伯、波斯、粟特商人经海陆两路汇聚广州、扬州、长安。
- 景教、祆教、摩尼教、伊斯兰教并存，多元宗教共存。

## 五、延伸

- **成语**：贞观之治、开天之治、安史之乱、马嵬之变、藩镇割据、五代十国、陈桥兵变。
- **典籍**：《贞观政要》《唐律疏议》《唐六典》《大唐西域记》《通典》《旧唐书》《新唐书》《资治通鉴》唐纪。
- **遗址**：唐长安城、大明宫遗址、龙门石窟唐段、敦煌莫高窟唐段、乾陵（高宗武后合葬）、昭陵、桥陵、南唐二陵。
- **影视**：电影《妖猫传》《长安三万里》；电视剧《贞观之治》《大唐荣耀》《大明宫词》；纪录片《大明宫》《中国通史》隋唐段。
- **必读人物**：杨坚、隋炀帝、唐太宗、魏征、玄奘、武则天、唐玄宗、杨贵妃、安禄山、郭子仪、李白、杜甫、白居易、韩愈、鉴真、一行、朱温、柴荣、李煜。

## 六、速记要点

1. 隋（581—618）短命但制度奠基；唐（618—907）是中国帝制盛世巅峰。
2. 三省六部+科举+均田+租庸调是隋唐四大制度。
3. 贞观（627—649）+开元（713—741）是两大盛世。
4. 755—763 安史之乱是唐由盛转衰的拐点。
5. 907 朱温代唐，五代十国开始，960 赵匡胤建宋。
6. 唐诗、书法、佛教汉化、国际化是唐文化四大贡献。
