# 春秋战国 · 礼崩乐坏与百家争鸣

> "春秋无义战。" ——《孟子·尽心下》

东周分**春秋**（前 770—前 476）与**战国**（前 475—前 221）两段。名义上"周天子"仍在，实则诸侯各自为政、兼并战争频繁，史称"礼崩乐坏"。但正是这种大动荡，孕育了中国思想的"轴心时代"。

## 一、春秋五霸

春秋时期，周天子无力号令诸侯，强侯以"尊王攘夷"为名号令天下，史称"霸主"。

| 霸主 | 国 | 主要事迹 |
| ---- | -- | -------- |
| 齐桓公 | 齐 | 任管仲改革，会盟葵丘，首倡"尊王攘夷" |
| 晋文公 | 晋 | 城濮之战胜楚，践土会盟 |
| 秦穆公 | 秦 | 称霸西戎，拓地千里 |
| 楚庄王 | 楚 | 邲之战胜晋，问鼎中原 |
| 宋襄公 / 吴王阖闾 / 越王勾践 | — | （五霸名单有多说，宋襄图霸未成；吴越争霸是春秋末期亮点）|

### 重要事件

- **城濮之战**（前 632）：晋文公退避三舍后败楚，奠定霸业。
- **吴越争霸**：阖闾攻楚入郢；夫差胜越；越王勾践卧薪尝胆，反灭吴（前 473）。
- **三家分晋**（前 453，前 403 受周威烈王册封）：晋被韩、赵、魏三家瓜分，**战国开端**。
- **田氏代齐**：齐国姜姓被田氏取代，但保留国号——典型的"卿大夫夺国"。

## 二、战国七雄

战国七雄：**齐、楚、燕、韩、赵、魏、秦**。

| 国 | 都城 | 特点 |
| -- | ---- | ---- |
| 齐 | 临淄 | 富庶、文化兴盛、稷下学宫 |
| 楚 | 郢 | 疆域最大、浪漫楚文化 |
| 燕 | 蓟 | 北方弱国，但燕昭王一度中兴 |
| 韩 | 新郑 | 最弱，先被秦吞 |
| 赵 | 邯郸 | 胡服骑射，军事强 |
| 魏 | 大梁 | 战国初霸，李悝变法 |
| 秦 | 咸阳 | 商鞅变法，最终统一 |

### 变法运动

战国是"改革竞赛"的时代，谁变法彻底谁就强。

| 变法 | 国 | 时间 | 亮点 |
| ---- | -- | ---- | ---- |
| 李悝变法 | 魏 | 前 422 | 著《法经》，重农、废世袭 |
| 吴起变法 | 楚 | 前 386 | 强兵、抑贵族，楚悼王死而法废 |
| 邹忌讽齐王 | 齐 | 前 357 | 广开言路，齐国大治 |
| 商鞅变法 | 秦 | 前 356—前 338 | 废井田、废世卿、行郡县、奖军功、连坐 |
| 胡服骑射 | 赵 | 前 307 | 学习游牧骑兵战术 |

> **商鞅变法**是其中最彻底、影响最深远的：它把秦国改造成一台"耕战机器"，奠定了统一六国的物质与制度基础。司马迁评："商君，天资刻薄人也。"

### 经典战役

- **马陵之战**（前 342）：齐孙膑诱魏庞涓至马陵，魏大败。"减灶之计"成军事教科书。
- **长平之战**（前 260）：秦白起坑杀赵降卒 40 万——战国规模最大、最惨烈一战，赵国元气大伤，秦国一强独大。

## 三、百家争鸣

"礼崩乐坏"催生思想大爆发，是中国思想的**轴心时代**。

| 学派 | 代表 | 核心主张 |
| ---- | ---- | -------- |
| 儒家 | 孔子、孟子、荀子 | 仁、礼、王道；性善/性恶之争 |
| 道家 | 老子、庄子 | 道法自然、无为而治、齐物逍遥 |
| 墨家 | 墨子 | 兼爱、非攻、节用、尚贤；先秦显学之一 |
| 法家 | 商鞅、韩非、李斯 | 法、术、势；耕战立国；君主集权 |
| 名家 | 惠施、公孙龙 | 名实之辩，"白马非马" |
| 阴阳家 | 邹衍 | 五德终始说，影响朝代更替解释 |
| 兵家 | 孙武、孙膑、吴起 | 《孙子兵法》"知己知彼，百战不殆" |
| 杂家 | 吕不韦《吕氏春秋》 | 兼采众家，倡导"贵公" |
| 农家 | 许行 | 君臣并耕，反对垄断 |

> **稷下学宫**（齐国）是当时的思想中心，孟子、荀子都曾在此讲学，学者称"稷下先生"，享受"不治而议论"的言论自由。这是中国最早的"高等学府"雏形。

## 四、社会与经济大变

### 1. 铁器牛耕

战国进入铁器时代，铁制农具与牛耕推广，使一家一户的小农经济成为可能，**井田制瓦解**，土地私有化起步。

### 2. 都江堰与郑国渠

- **都江堰**（前 256 前后，李冰父子）：四川岷江水利工程，至今仍在用，使成都平原成"天府之国"。
- **郑国渠**（前 246 开凿）：秦国关中水利，关中沃野千里。

### 3. 商业与城市

- 临淄、邯郸、大梁、郢、咸阳都是人口十万级的大都市。
- 出现大商人：范蠡（陶朱公）、吕不韦（奇货可居，从商人到丞相）。
- 金属货币普及：布币、刀币、圜钱、蚁鼻钱四大体系。

## 五、文化成就

- **文学**：《诗经》（春秋编成）、《楚辞》（屈原《离骚》《九歌》），开创中国诗歌的"风骚"传统。
- **史学**：《春秋》（编年体）、《左传》《谷梁传》《公羊传》三传；《国语》《战国策》（国别体）。
- **哲学**：诸子百家著作奠定中国哲学基础。
- **科技**：《考工记》（工艺）、《黄帝内经》（医学）、《墨经》（力学光学）。

## 六、延伸

- **成语**：退避三舍、卧薪尝胆、围魏救赵、减灶诱敌、朝三暮四、刻舟求剑、守株待兔、滥竽充数、五十步笑百步、白马非马。
- **典籍**：《论语》《孟子》《老子》《庄子》《韩非子》《孙子兵法》《左传》《战国策》。
- **遗址**：齐都临淄遗址、邯郸赵王城、燕下都、秦都咸阳遗址；都江堰、郑国渠遗址仍在使用。
- **影视**：电影《荆轲刺秦王》《英雄》；电视剧《大秦帝国》系列（裂变/纵横/崛起/天下）；纪录片《楚国八百年》《喋殇长平》。
- **必读人物**：管仲、孔子、孙武、吴起、商鞅、孟子、屈原、苏秦张仪、廉颇蔺相如、吕不韦、韩非、李斯。

## 七、速记要点

1. 东周分春秋（前 770—前 476）、战国（前 475—前 221）。
2. 春秋五霸：齐桓、晋文、秦穆、楚庄、（多版本第五人）。
3. 战国七雄：齐楚燕韩赵魏秦，自东向南向北排列。
4. 三家分晋（前 453）是春秋战国的分水岭。
5. 商鞅变法是战国变法中最彻底者，为秦统一奠基。
6. 百家争鸣是中国思想史上第一次高峰，影响后世两千年。
7. 长平之战（前 260）后，秦统一只是时间问题。
