# 史前与传说时代 · 三皇五帝

> "自从盘古开天地，三皇五帝到于今。"

这是中国历史的"史前"阶段：还没有成熟文字、没有确切纪年，靠考古与口传共同拼出轮廓。它的结尾接到夏朝——一般认为约前 2070 年——从此进入"信史时代"。

## 一、考古上的中国史前史

中国境内的古人类演化链相当完整，是研究人类起源的重要区域之一。

| 阶段 | 代表遗址 | 时间 | 看点 |
| ---- | -------- | ---- | ---- |
| 直立人 | 元谋人（云南） | 约 170 万年前 | 中国境内已知最早人类化石 |
| 直立人 | 北京人（周口店） | 约 70—20 万年前 | 用火、打制石器，群居 |
| 早期智人 | 大荔人、金牛山人 | 约 20—10 万年前 | 形态介于直立人与现代人之间 |
| 晚期智人 | 山顶洞人 | 约 3 万年前 | 钻孔取火、骨针缝衣、葬仪、装饰品 |

到了约 **1 万年前**，进入新石器时代，农业起源，开始定居、制陶、养家畜：

| 文化 | 区域 | 时间 | 代表性发现 |
| ---- | ---- | ---- | ---- |
| 裴李岗、磁山 | 黄河中游 | 约前 7000—前 5000 年 | 粟（小米）农业、红陶 |
| 仰韶文化 | 黄河中游 | 约前 5000—前 3000 年 | 彩陶、半地穴房屋、聚落 |
| 红山文化 | 西辽河 | 约前 4700—前 2900 年 | 玉猪龙、女神庙、祭坛 |
| 大汶口文化 | 山东 | 约前 4300—前 2500 年 | 黑陶、文字符号萌芽 |
| 良渚文化 | 太湖 | 约前 3300—前 2300 年 | 玉琮玉璧、巨大古城、水利系统 |
| 龙山文化 | 黄河中下游 | 约前 2400—前 2000 年 | 蛋壳黑陶、城址、阶级分化 |

> **关键概念**："中华文明探源工程"近年的成果显示：良渚已具备早期国家形态（城墙、水利、玉礼器、阶级分化），说明在 **5300 年前**长江下游已进入"古国"阶段。这是"五千年文明"说法的实证基础。

## 二、传说时代：三皇五帝

文字发明之前，先民将集体记忆凝缩为若干"圣王"形象。不同典籍对三皇五帝的具体名单说法不一，下面是较通行的一版：

### 三皇（人类早期三大进步的拟人化）

| 名号 | 主要贡献 | 象征意义 |
| ---- | -------- | -------- |
| 燧人氏 | 钻木取火 | 火的掌握，告别茹毛饮血 |
| 伏羲氏 | 创八卦、制嫁娶 | 婚姻制度、宇宙观萌芽 |
| 神农氏（炎帝） | 尝百草、制耒耜 | 农业与医药起源 |

### 五帝（部落联盟首领的拟人化）

主要依据《史记·五帝本纪》：

1. **黄帝**：姬姓，号轩辕氏。阪泉、涿鹿两战，胜炎帝、擒蚩尤，被尊为华夏始祖。
2. **颛顼**：黄帝之孙。"绝地天通"，将神权收归王权。
3. **帝喾**：黄帝曾孙。立节气、定历法雏形。
4. **尧**：号陶唐氏。设官、定四时；晚年**禅让**于舜。
5. **舜**：号有虞氏。流四凶、命禹治水；禅让于禹。

### 几个常被问到的"小问题"

- **炎黄子孙**怎么来？黄帝与炎帝两大部落融合后成为华夏主干，后世华人都自称"炎黄子孙"。
- **禅让制**真的"选贤不选亲"吗？史载尧让舜、舜让禹，是儒家理想化的政治叙事。现代学者认为也可能是部落联盟内部的贵族推选制。
- **大禹治水**真有那么神？考古发现黄河中下游在距今 4000 年前后确有大洪水痕迹，鲧、禹两代治水的传说应当有真实底本。

## 三、大事速记

- **涿鹿之战**：黄帝与蚩尤决战于涿鹿之野，相传蚩尤作大雾，黄帝造指南车破之。象征华夏部落联盟战胜东夷集团。
- **阪泉之战**：黄帝与炎帝三战，最终融合，奠定"炎黄"主体。
- **大禹治水**：禹采用"疏导"之法，十三年三过家门而不入。洪水退后，他被舜选为继承人，其子启建立夏朝，"家天下"开端。

## 四、文化成就

- **科技**：火的使用、石器打制磨制、弓箭、陶器、丝织（仰韶出土过蚕蛹俑）。
- **思想**：八卦与阴阳五行观念的雏形；天人合一、敬天法祖的早期信仰。
- **制度**：从群婚到对偶婚；从氏族到部落，再到部落联盟；禅让制是联盟首领更替的拟制。

## 五、延伸

- **成语**："三过家门而不入""开天辟地""钻木取火""尝百草"。
- **典籍**：《山海经》《楚辞·天问》《史记·五帝本纪》《帝王世纪》。神话与历史交织，宜对照阅读。
- **遗址**：良渚古城遗址（杭州，世界遗产）、二里头夏都遗址（洛阳偃师）、陶寺遗址（山西襄汾，疑即"尧都"）、石峁古城（陕西神木）。
- **影视**：纪录片《中国通史》第 1—4 集、《良渚》《何以中国》（B 站可看）。
- **争议**：夏朝是否真实存在？目前二里头遗址证据较强但缺自证文字，仍属"信史边缘"。考古学界主流认可二里头为夏代中晚期都城。

## 六、速记要点

1. 元谋人（170 万年前）→ 北京人（70—20 万年前）→ 山顶洞人（3 万年前）。
2. 距今 1 万年开始新石器时代，粟黍（北方）+ 水稻（南方）的"南稻北粟"格局奠定。
3. 距今 5000 年前后，良渚、红山、大汶口、仰韶等同时进入"古国"阶段，是中国"五千年文明"的实证。
4. 三皇五帝是部落联盟首领的人格化记忆，禅让是联盟推选制的理想化叙事。
5. 大禹治水后，子启建夏，"家天下"取代"公天下"，进入信史时代。
