# 中国通史 · 导读总览

> "以史为鉴，可以知兴替。" ——《旧唐书·魏徵传》

中国历史是一条奔流四千余年的长河。它不是简单的王朝更替，而是地理、民族、制度、文化不断碰撞、融合与再造的过程。本模块按**时间分期**重新编排，让读者从"统一—分裂—再统一"的脉动中，把握华夏文明从部落联盟到现代国家的演化路径。

## 中国历史的几条主线

### 1. 政治主线：从分封到郡县，从贵族到官僚

- **西周分封**：把土地与人民分给同姓子弟和功臣，建立封国，靠血缘与礼乐维系天下。
- **秦废分封**：废诸侯、立郡县，官员由中央任命、不可世袭，中国从此走上"中央集权+官僚治理"的道路。
- **汉至隋唐**：郡县与分封反复拉锯，最终郡县制全面胜出；察举、九品中正、科举层层迭代，官员选拔从血统走向考试。
- **宋以后**：宰相权力被分割，皇权持续加强；明废除丞相，清设军机处，专制达到顶峰。

### 2. 经济主线：从井田到小农，从农业到商业

- **井田制**：周代理想中的公有共耕土地制度，春秋时逐步瓦解。
- **小农经济**：商鞅变法后，自耕农家庭成为国家税源与兵源的基本单位。
- **重农抑商**：秦汉以降的国策，但唐宋以后商品经济仍顽强发展，宋代城市、纸币、海外贸易登峰造极。
- **赋税合并**：从租庸调到一条鞭法再到摊丁入亩，人头税并入田赋，农民身份逐渐松绑。

### 3. 民族主线：从华夏到多元一体

- **华夏成形**：西周"诸夏"观念出现，与四夷相对。
- **第一次大融合**：春秋战国，楚、秦、吴、越等边缘政权跻身"诸夏"，奠定汉人前身。
- **第二次大融合**：魏晋南北朝，五胡入华，鲜卑汉化，孕育出隋唐的混合型帝国。
- **第三次大融合**：辽宋夏金元，多政权并立，元朝大一统后汉、蒙、回、藏等更紧密地连为一体。
- **清代的整合**：满、蒙、藏、疆与内地同属一个政治共同体，奠定今日中国的版图与民族格局。

### 4. 思想主线：从百家到儒术，从儒术到理学

- **先秦**：百家争鸣，儒、墨、道、法、阴阳、名、兵各有侧重。
- **汉武帝**：罢黜百家、独尊儒术，儒家被立为官方意识形态。
- **魏晋**：玄学兴起，道教组织化，佛教大规模传入。
- **隋唐**：三教并立，佛教汉化禅宗兴起。
- **宋明**：理学（道学）将儒、释、道熔铸为一，朱熹、王阳明是两座高峰。
- **清末**：西学东渐，经学解体，新文化运动后多元思潮并存。

## 中国历史的几个"为什么"

| 现象 | 浅释 |
| ---- | ---- |
| 为什么中国没有像欧洲那样长期分裂？ | 文字、官僚体系、儒家经典的统一，使"大一统"成为默认的政治想象。 |
| 为什么游牧民族屡屡入主中原？ | 草原政权军事机动性强，中原王朝衰落时往往被乘虚而入；但入主后又必须接受农耕治理方式。 |
| 为什么科举能延续 1300 年？ | 它把读书、做官、社会上升绑定在一起，既选拔人才，又凝聚了价值共识。 |
| 为什么近代落后于西方？ | 闭关与海禁抑制了海洋冒险，专制强化抑制了思想突破，小农经济抑制了资本积累。 |

## 怎样读本模块

1. 每篇按"时间—事件—人物—制度—文化"的顺序展开，最后附**延伸**（成语典故、文物、遗址、影视推荐）。
2. 长时段分为多节，方便碎片阅读；每节都给出**速记要点**。
3. 对有争议的史实（如夏朝是否存在、秦始皇功过），同时列出现代主流观点，不强行定论。
4. 时间一律以"公元 X 年"统一格式，便于对照。

## 延伸：读中国史的几条进路

- **典籍入门**：《史记》《资治通鉴》是叙事史的双璧，配合钱穆《国史大纲》、吕思勉《中国通史》阅读更佳。
- **文物入门**：博物馆比书本更直观——国家博物馆、陕西历史博物馆、河南博物院、湖南省博物馆、三星堆博物馆都是"看得见的历史"。
- **地图入门**：谭其骧《中国历史地图集》是必备工具；先看疆域，再读事件，能避免"空读"。
- **问题入门**：与其背年份，不如带着问题读——比如"为什么中国经济重心南移？""为什么宋代文化鼎盛却军事疲弱？"
