# 三国两晋南北朝 · 大分裂中的融合

> "天下大势，分久必合，合久必分。" ——《三国演义》

220 年曹丕代汉，到 589 年隋灭陈统一，中国走过 369 年的分裂动荡。但这并非纯粹的"黑暗时代"——**民族大融合、江南大开发、佛教汉化、玄学兴起**都在此时埋下种子，孕育出隋唐那座多元一体的盛世帝国。

## 一、三国（220—280）

### 1. 鼎立格局

| 国 | 建立 | 都城 | 皇帝代表 | 势力范围 |
| -- | ---- | ---- | -------- | -------- |
| 魏 | 220 曹丕 | 洛阳 | 曹操、曹丕、曹叡 | 中原九州 |
| 蜀汉 | 221 刘备 | 成都 | 刘备、刘禅 | 益州一隅 |
| 吴 | 222 孙权称王，229 称帝 | 建业 | 孙权、孙亮、孙休、孙皓 | 江东六郡到岭南 |

### 2. 关键战役

- **官渡之战**（200）：曹操胜袁绍，统一北方。
- **赤壁之战**（208）：孙刘联军以少胜多破曹，三国鼎立成局。
- **猇亭之战（夷陵之战）**（222）：刘备攻吴为关羽复仇，被陆逊火攻破之，蜀汉从此退出荆州。
- **五丈原之战**（234）：诸葛亮最后一次北伐，病逝军中。

### 3. 三国制度

- **魏**：实行**九品中正制**（陈群创），以门第品评人才，本是权宜之计，结果固化成"上品无寒门，下品无势族"。
- **蜀**：诸葛亮治蜀，务农积谷，"七擒孟获"稳定南中；六出祁山北伐，耗国力。
- **吴**：山越开发、屯田制、海路联系夷洲（台湾）；江南开始步入"开发期"。

## 二、西晋（265—316）

### 1. 短暂统一

- 司马氏三代（懿、师、昭）架空曹魏，265 年司马炎代魏建晋，定都洛阳，史称**西晋**。
- 280 年晋灭吴，三国归一。
- 武帝前期"太康之治"短暂繁荣；后期迅速败坏。

### 2. 大封宗室与八王之乱

- 武帝大封宗室 27 王，意图"以藩屏晋"，结果重蹈汉初覆辙。
- 291—306 年**八王之乱**，宗室诸王混战，国力耗尽。
- 内乱引发**永嘉之乱**：匈奴刘渊、刘聪南下，311 破洛阳掳怀帝，316 破长安掳愍帝，西晋亡。

## 三、东晋与南朝（317—589）

### 1. 衣冠南渡与东晋

- 317 年琅邪王司马睿在建康（今南京）称帝，史称**东晋**。
- 北方士族"衣冠南渡"，把中原制度、文化、技术带至江南，江南开发加速。
- **门阀政治**：王、谢、桓、谢等大族与皇权共治，"王与马共天下"。
- **淝水之战**（383）：谢安、谢玄以八万破前秦苻坚八十万，江南免于沦陷。

### 2. 南朝（420—589）

| 朝代 | 起止 | 都城 | 创建者 |
| ---- | ---- | ---- | ---- |
| 宋 | 420—479 | 建康 | 刘裕 |
| 齐 | 479—502 | 建康 | 萧道成 |
| 梁 | 502—557 | 建康 | 萧衍 |
| 陈 | 557—589 | 建康 | 陈霸先 |

南朝文化鼎盛：

- **宋**：刘裕北伐一度收复洛阳、长安；元嘉之治短暂繁荣。
- **齐**：齐明帝崇佛，建康佛寺林立。
- **梁**：梁武帝萧衍在位 48 年，崇佛四次舍身；侯景之乱（548—552）毁掉江南繁荣。
- **陈**：陈霸先、陈后主（写《玉树后庭花》的亡国之君）。589 年隋军渡江破建康，陈亡。

## 四、十六国与北朝

### 1. 五胡十六国（317—439）

永嘉之乱后，北方进入"五胡十六国"时代，"五胡"指**匈奴、鲜卑、羯、氐、羌**。

- 重要政权：前赵（匈奴）、后赵（羯）、前燕（鲜卑）、前秦（氐）、后秦（羌）、成汉（氐）等。
- 前秦一度统一北方，淝水败后瓦解。
- 北魏崔浩《国书》案、汉胡矛盾激化贯穿此期。

### 2. 北朝（386—581）

| 朝代 | 起止 | 民族 | 都城 |
| ---- | ---- | ---- | ---- |
| 北魏 | 386—534 | 鲜卑拓跋 | 平城→洛阳 |
| 东魏 | 534—550 | 鲜卑 | 邺 |
| 西魏 | 535—556 | 鲜卑 | 长安 |
| 北齐 | 550—577 | 汉化鲜卑 | 邺 |
| 北周 | 557—581 | 鲜卑宇文 | 长安 |

#### 北魏孝文帝改革

**北魏孝文帝拓跋宏**（471—499 在位）是这一时期最关键的人物，他的汉化改革重塑了北方格局：

- **迁都洛阳**（494）：摆脱平城保守贵族束缚。
- **改汉姓**：拓跋→元，独孤→刘等。
- **禁胡服、说汉话**：30 岁以下官员一律说汉语。
- **鼓励通婚**：鲜卑贵族与汉族高门联姻。
- **行均田、立三长**：国家分田给农民，重建户籍。

> **意义**：这是中国历史上**第一次主动、自上而下的民族大融合**，鲜卑汉化后融入汉族，也为隋唐统治者（杨坚、李渊母系皆有鲜卑血统）奠定"胡汉混合"的世家基础。

#### 东西魏分裂与北周统一北方

- 534 年北魏分裂为东魏（高欢）和西魏（宇文泰）。
- 550 年高洋代东魏建北齐；557 年宇文觉代西魏建北周。
- 577 年北周武帝灭北齐，统一北方。
- 581 年杨坚代周建隋。

## 五、分裂时代的精神世界

### 1. 玄学兴起

- 魏晋时期，士人对汉末腐儒僵化经学反叛，兴起**玄学**，谈"三玄"（《老》《庄》《易》）。
- 何晏、王弼倡"贵无论"；嵇康、阮籍等"竹林七贤"倡"越名教而任自然"。
- 魏晋风度：清谈、饮酒、服五石散、崇尚仪容——是中国文人精神独立的萌芽。

### 2. 道教组织化

- 张道陵在巴蜀创"五斗米道"（东汉末），到魏晋正式组织化。
- 葛洪《抱朴子》构建炼丹与神仙理论，奠定后世道教基础。
- 北魏寇谦之改革，道教成北魏国教。

### 3. 佛教汉化

- 两汉之际传入，魏晋南北朝大盛。
- 后赵佛图澄、前秦道安、后秦鸠摩罗什三大僧人推动佛经汉译。
- **云冈石窟**（北魏早期，大同）、**龙门石窟**（北魏后期至唐，洛阳）、**敦煌莫高窟**（北凉至元）三大石窟艺术盛于此期。
- "南朝四百八十寺，多少楼台烟雨中"——梁武帝时建康佛寺极盛。

### 4. 文学与艺术

- **文学**：建安文学（三曹七子）、陶渊明田园诗、谢灵运山水诗、《世说新语》。
- **书法**：王羲之"书圣"，《兰亭序》"天下第一行书"。
- **绘画**：顾恺之《女史箴图》《洛神赋图》。
- **数学**：祖冲之将圆周率算到小数点后 7 位（3.1415926—3.1415927 之间），领先世界近千年。

## 六、政治制度的演进

| 制度 | 演进 |
| ---- | ---- |
| 九品中正制 | 魏晋行 → 门阀固化 → 隋废 |
| 都督中外诸军事 | 魏晋设，演为北朝"府兵制" |
| 州郡县三级 | 由监察区→行政区，州郡县化定型 |
| 均田制 | 北魏创立 → 隋唐沿用 → 中唐崩 |

## 七、延伸

- **成语**：三顾茅庐、鞠躬尽瘁死而后已、乐不思蜀、司马昭之心路人皆知、风声鹤唳草木皆兵、投鞭断流、宁为玉碎不为瓦全。
- **典籍**：《三国志》（陈寿）、《后汉书》（范晔）、《世说新语》（刘义庆）、《水经注》（郦道元）、《文心雕龙》（刘勰）。
- **遗址**：南京六朝陵墓石刻、龙门石窟、云冈石窟、敦煌莫高窟、麦积山石窟、邺城遗址。
- **影视**：1994 版《三国演义》电视剧、电影《赤壁》《见龙卸甲》《绣春刀》；纪录片《从三国到两晋南北朝》《敦煌》《河西走廊》。
- **必读人物**：曹操、刘备、孙权、诸葛亮、司马懿、王羲之、陶渊明、谢安、北魏孝文帝、崔浩、宇文泰、苏绰。

## 八、速记要点

1. 三国 220—280，西晋短暂统一 265—316。
2. 317 东晋南渡，南北分裂开始，持续至 589 隋统一。
3. 北方五胡十六国 → 北魏 → 东西魏 → 北齐北周；南方东晋 → 宋齐梁陈。
4. 北魏孝文帝改革是汉胡大融合的关键节点，奠定隋唐胡汉混合世家基础。
5. 文化三大贡献：玄学兴起、道教组织化、佛教汉化。
6. 南朝佛教与艺术鼎盛，北朝石窟与均田府兵并行，为隋唐盛世铺垫。
