# 秦汉 · 大一统的奠基

> "百代都行秦政法。" ——毛泽东

秦汉是中国"大一统"的奠基期。从秦始皇统一六国到东汉灭亡（前 221—公元 220），这 441 年里，**郡县制、皇帝制、独尊儒术、丝路开通、官僚体系**这些"中国基因"基本成型，影响直至 1912 年清帝退位。

## 一、秦朝（前 221—前 207）

### 1. 统一六国

秦王嬴政用远交近攻之策，自前 230 至前 221，依次灭韩、赵、魏、楚、燕、齐六国，完成统一。自称"始皇帝"，定都咸阳，确立**皇帝制**与中央集权。

### 2. 制度：千古"秦政法"

| 措施 | 内容 | 意义 |
| ---- | ---- | ---- |
| 废分封、行郡县 | 全国设 36 郡（后增），郡守、县令由中央任免 | 终结世袭分封，开创官僚治理 |
| 书同文 | 推行小篆 | 文字统一，奠定文化共同体 |
| 车同轨 | 统一车轴宽度 | 全国交通网络化 |
| 行同伦 | 统一礼俗 | 文化整合 |
| 统一度量衡 | 商鞅升 → 秦统一标准 | 经济标准化 |
| 修驰道、直道 | 通九原、抵匈奴 | 国防与行政速度 |
| 修长城 | 隐恬北击匈奴后连接旧长城 | 北疆防线 |
| 焚书坑儒 | 禁私学、坑方士 | 思想钳制，影响恶劣 |

### 3. 速亡之谜

秦朝传二世而亡（前 207），仅 15 年。原因：

- **徭役过重**：长城、阿房宫、骊山陵、驰道同时进行，民力枯竭。
- **严刑峻法**：陈胜吴广因雨失期"皆当斩"，逼反大泽乡。
- **二世无能**：胡亥听赵高谗杀扶苏、蒙恬、李斯，朝政崩坏。

### 4. 大泽乡起义与楚汉相争

- 前 209 陈胜、吴广"**王侯将相宁有种乎**"起事，虽败犹荣——这是**中国第一次大规模农民起义**。
- 项梁、项羽起兵吴中；刘邦起兵沛县。
- 巨鹿之战（前 207）：项羽破釜沉舟，灭秦主力。
- 前 206 刘邦先入关中，秦王子婴出降，秦亡。
- 楚汉战争（前 206—前 202）：刘邦明修栈道、暗渡陈仓，与项羽争天下。
- 前 202 垓下之战，四面楚歌、霸王别姬，项羽自刎乌江。刘邦称帝建汉，是为**汉高祖**。

## 二、西汉（前 202—公元 9）

### 1. 立国与"无为"

- 刘邦定都长安（今西安），史称**西汉**。
- 鉴秦亡教训，行**郡国并行制**：京畿设郡，边远封同姓子弟为诸侯王。
- **黄老无为**：经惠、文、景三朝轻徭薄赋、与民休息。
- 文景之治：汉文帝、汉景帝时期，国力恢复，史称"文景之治"。

### 2. 七国之乱与削藩

- 景帝时诸侯势大，晁错倡"削藩"，吴楚等七国以"清君侧"为名叛乱（前 154）。
- 周亚夫三月平叛。从此诸侯被削权，中央集权加强。
- 武帝颁"**推恩令**"（主父偃倡）：诸侯封地由诸子分继承，几代后自动瓦解。

### 3. 汉武帝：盛世的全方位扩张

汉武帝刘彻在位 54 年（前 141—前 87），是西汉也是中国帝制史上少有的"全能型"大帝。

#### 政治

- 设**中朝（内朝）**架空丞相，加强皇权。
- 设**刺史**：分十三州部刺史，巡视地方，监察郡守。
- 察举制：地方举孝廉，建立官员选拔的"儒生通道"。

#### 思想

- "**罢黜百家，独尊儒术**"：董仲舒提议，儒家被立为官方意识形态，五经立学官。
- 融合阴阳五行、法家行政的"汉代儒学"诞生。

#### 军事与外交

- 三大征伐：
  - **北击匈奴**：卫青、霍去病三战（河南、河西、漠北），匈奴远遁，漠南无王庭。
  - 河西战役后设**河西四郡**：武威、张掖、酒泉、敦煌。
  - 张骞通西域（前 138、前 119）：开通**丝绸之路**，"凿空"之功。
- 东北置乐浪等四郡；南方平定南越、西南夷，疆域达西汉鼎盛。

#### 文化

- **司马迁《史记》**：中国第一部纪传体通史，"史家之绝唱，无韵之离骚"。
- 设乐府采集民歌；《汉赋》达鼎盛（司马相如、扬雄）。
- 太学：设五经博士、博士弟子员，是国立高等学府的雏形。

### 4. 西汉后期

- **昭宣中兴**：霍光辅政，与匈奴和亲（**昭君出塞**，前 33）。
- **王莽篡汉**（公元 9）：外戚王莽代汉建"新"，推行托古改制，引发绿林赤眉起义，新朝 23 年而亡。

## 三、东汉（25—220）

### 1. 光武中兴

- 刘秀（汉光武帝）出身宗室，昆阳之战以少胜多破王莽主力，25 年称帝定都洛阳，史称**东汉**。
- 退功臣、进文吏，简化行政，与民休息，史称"**光武中兴**"。
- 明章之治：明帝、章帝时政治清明，班超通使西域（73—102），甘英欲遣大秦（罗马）未果。

### 2. 东汉三大顽疾

东汉名义绵延近 200 年，但有三条结构性顽疾始终未愈：

| 顽疾 | 表现 | 后果 |
| ---- | ---- | ---- |
| 外戚与宦官交替专权 | 章帝后皇后多幼主即位，太后父兄掌权；幼帝长大后用宦官反制 | 党锢之祸，士人遭大狱 |
| 豪强兼并 | 大地主田庄（坞壁）遍布，自给自足，藏匿人口 | 国家税源兵源枯竭，分裂土壤 |
| 边患反复 | 西羌百年战争耗尽国力 | 北部边防崩溃 |

### 3. 黄巾起义与三国序幕

- 184 年张角以太平道组织**黄巾起义**，动摇东汉根基。
- 朝廷放权于州牧镇压，导致**州牧割据**，地方军阀并起。
- 196 年曹操迎汉献帝于许，"挟天子以令诸侯"。
- 200 年官渡之战，曹操击败袁绍，统一北方。
- 208 年**赤壁之战**，孙刘联军破曹，三国鼎立格局形成。
- 220 年曹丕代汉，东汉亡。

## 四、文化科技：汉代的世界级贡献

| 领域 | 成就 | 影响 |
| ---- | ---- | ---- |
| 史学 | 司马迁《史记》、班固《汉书》 | 纪传体正史范式 |
| 科技 | 蔡伦改进造纸术（105 年） | 改变人类文明传播方式 |
| 科技 | 张衡地动仪（132 年）、浑天仪 | 早期地震天文仪器 |
| 医学 | 张仲景《伤寒杂病论》、华佗麻沸散 | 中医临床基础 |
| 数学 | 《九章算术》成书 | 中国古代数学经典 |
| 思想 | 经学（今文经 vs 古文经）；王充《论衡》 | 唯物思想萌芽 |
| 宗教 | 佛教自西域传入，楚王英奉佛（65 年） | 中国佛教之始 |

## 五、秦汉制度的深远影响

- **皇帝制**：从此 2100 余年中国都行此制，至 1912。
- **郡县制**：地方治理的基本形态，至今仍有县制。
- **官僚选拔**：从察举到科举的源头。
- **儒家官方化**：经学传统延续到 1905 废科举。
- **丝路与西域**：中国第一次以"国家力量"走向世界。

## 六、延伸

- **成语**：破釜沉舟、四面楚歌、明修栈道暗渡陈仓、运筹帷幄、约法三章、孺子可教、投笔从戎、不入虎穴焉得虎子、得陇望蜀。
- **典籍**：《史记》《汉书》《后汉书》《三国志》《盐铁论》《说文解字》《九章算术》。
- **遗址**：秦始皇陵兵马俑（世界遗产）、汉长安城、未央宫遗址、洛阳汉魏故城、马王堆汉墓、满城汉墓、海昏侯墓。
- **影视**：电影《荆轲刺秦王》《鸿门宴》《赤壁》；电视剧《汉武大帝》《大秦帝国》《三国》（1994 版）；纪录片《从秦始皇到汉武帝》《河西走廊》。
- **必读人物**：秦始皇、李斯、项羽、刘邦、汉武帝、卫青、霍去病、张骞、司马迁、王莽、刘秀、班超、蔡伦、张衡、张仲景。

## 七、速记要点

1. 秦朝（前 221—前 207）二世而亡，但制度千古。
2. 汉分西汉（前 202—9）与东汉（25—220），中间隔王莽新朝（9—23）。
3. 汉武帝是西汉盛主：北击匈奴、通西域、独尊儒术。
4. 东汉三大顽疾：外戚宦官、豪强兼并、边患反复。
5. 220 年曹丕代汉，三国开始。
6. 汉代四大贡献：造纸、《史记》、独尊儒术、丝路。
