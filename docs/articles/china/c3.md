# 夏商西周 · 三代

> "殷因于夏礼，所损益，可知也；周因于殷礼，所损益，可知也。" ——《论语·为政》

夏、商、周并称"三代"，是华夏文明的奠基期。这一阶段的最大特征是：青铜铸造达到巅峰、文字成熟、分封制与宗法制成为后世政治与社会的母本。

## 一、夏朝（约前 2070—前 1600）

### 1. 建立与传说

- 禹治水有功，被舜选为继承人；禹死后，其子**启**夺得首领之位，"**家天下**"取代禅让制。
- 都城相传在阳翟（今河南禹州）；现代考古学主流将**二里头遗址**（河南偃师）视为夏代中晚期都城。
- 第三代王**太康**失国，被后羿篡夺（"太康失国""后羿代夏"），少康中兴，史称"少康中兴"。

### 2. 文化与制度

- **青铜器萌芽**：二里头出土的青铜爵、斝，是目前所知中国最早的礼器铜器组合。
- **宫室雏形**：二里头发现中国最早的宫殿基址，奠定了后世"宫城—皇城—京城"格局的雏形。
- **夏小正**：相传为夏代历书，记录星象、农事，是后世农历的远祖。

### 3. 灭亡

末王**桀**暴虐荒淫，被商汤击败于鸣条（今山西运城附近），夏亡。后世把"桀纣"并称暴君代名词。

## 二、商朝（约前 1600—前 1046）

### 1. 兴衰梗概

- **汤**灭夏建商，初都于亳。商前期屡次迁都，至**盘庚**迁都于殷（今河南安阳），从此稳定，故又称"殷商"。
- **武丁中兴**：武丁在位 59 年，妻妇好（中国第一位有据可查的女将军）征伐四方，疆域大为扩展。
- 商末王**纣**，刚愎淫暴，攻东夷耗国力，被周武王联合西方诸部于牧野击溃，自焚于鹿台。

### 2. 重器：甲骨文与青铜器

#### 甲骨文

- 刻在龟甲、兽骨上的占卜记录，是**中国已知最早的成熟文字**。
- 内容涉及祭祀、战争、农事、田猎、疾病、天象，是研究商代的第一手资料。
- 已发现单字约 4500 个，已识读约 1500 个。结构上已具备"六书"（象形、指事、会意、形声、转注、假借）的雏形。

#### 青铜器

- 司母戊鼎（又称后母戊鼎，重 832.84 公斤）是已发现最大最重的商代铜器，象征王权。
- 铸造采用"块范法"，纹饰以饕餮纹（兽面纹）为主，神秘威严。
- 青铜主要用来做**礼器与兵器**，农具仍以石器、骨器为主——这反映出青铜是"国之重器"，不是大众生产工具。

### 3. 信仰与王权

- 商人**尚鬼**，事无大小皆卜，神权色彩浓重。
- 王既是政治领袖也是最高祭司，"王"字本身像斧钺，象征征伐与祭祀之权。
- 商代已有"上帝"观念，是周代"天命"思想的源头。

## 三、西周（前 1046—前 771）

### 1. 建国

- 周原居西陲（今陕西关中），文王姬昌积蓄国力，其子武王姬发牧野之战灭商。
- 周初大封建：分封同姓子弟、异姓功臣、先代后裔为诸侯，"以藩屏周"。
- 周公旦摄政七年，平三监之乱，营建东都洛邑（今洛阳），制礼作乐，奠定周代制度基础。

### 2. 制度：分封、宗法、礼乐

#### 分封制

- 周王自称"天子"，把土地与人民分封给诸侯；诸侯再分封给卿大夫；卿大夫再分封给士。
- 形成天子—诸侯—卿大夫—士—庶人的层级。
- 诸侯义务：镇守疆土、随从作战、交纳贡赋、朝觐述职。

#### 宗法制

- **嫡长子继承制**为核心：正妻所生长子（嫡长子）享有优先继承权。
- 大宗与小宗：嫡长子一脉为"大宗"，余子为"小宗"，大宗永远主祭始祖。
- 宗法制与分封制互为表里，构成"家国同构"的政治结构——后世"家族伦理=国家伦理"由此定型。

#### 礼乐制

- 周礼规定不同等级的祭祀、用乐、服饰、车马、宫室规格，"礼"区分尊卑，"乐"调和上下。
- "刑不上大夫，礼不下庶人"——贵族以礼自律，庶人以刑约束。
- 春秋时孔子慨叹"礼崩乐坏"，正指此制度的崩溃。

### 3. 国祚与衰亡

- **成康之治**：成王、康王时期，刑罚四十余年不用，是西周盛世。
- **昭王南征不复**：周昭王南伐荆楚，死于汉水，是西周由盛转衰的标志。
- **厉王弭谤**：厉王禁止国人议论朝政，引发"国人暴动"，厉王出奔，由周、召二公执政，史称"**共和行政**"（前 841 年），这是**中国历史有确切纪年的开始**。
- **幽王烽火戏诸侯**（实为废嫡立庶引发的诸侯内乱）后，申侯联合犬戎攻破镐京，幽王被杀于骊山，西周亡。
- 平王东迁洛邑，东周（春秋战国）开始。

## 四、三代制度的"中国基因"

| 制度 | 影响 |
| ---- | ---- |
| 嫡长子继承 | 中国皇位继承原则，影响至清 |
| 宗法 | 后世家谱、宗祠、家族文化的源头 |
| 分封 | 郡县制前的主要政治模式；汉代仍部分保留 |
| 礼乐 | 儒家"克己复礼"的对象，影响中国礼制两千年 |
| 天命观 | "敬天保民""以德配天"，是儒家民本思想的源头 |
| 农耕基础 | "重农抑商"政策的起点 |

## 五、文化成就

- **青铜艺术**：商代器形厚重神秘，西周器形典雅纹饰简朴；金文（钟鼎文）由简到繁，是研究西周史的核心史料。
- **历法**：周代确立"十二月"制，置闰调整阴阳合历，至今农历框架未变。
- **诗经**：中国最早诗歌总集，其中《大雅》《周颂》多反映西周政治与祭祀生活。
- **思想**：天命、民本、敬德思想成型，是儒家学说的母体。

## 六、延伸

- **成语**："桀犬吠尧""助纣为虐""牧野之战""一鼓作气"（夏商周典故繁多）。
- **典籍**：《尚书》《诗经》《史记·夏本纪/殷本纪/周本纪》《竹书纪年》。
- **遗址与文物**：殷墟（安阳，世界遗产，甲骨与妇好墓）、二里头（偃师）、后母戊鼎（国博）、利簋（铭文记武王伐纣日期）、毛公鼎（台北故宫）。
- **影视**：纪录片《中国》第 1—2 集、《国家宝藏》第一季。
- **争议**：夏代是否"信史"？二里头是否即夏都？学界主流已认可，但缺乏文字自证，仍存微调空间。

## 七、速记要点

1. 三代时间：夏（约前 2070—前 1600）、商（约前 1600—前 1046）、西周（前 1046—前 771）。
2. 三大制度：分封（封邦建卫）、宗法（嫡长继承）、礼乐（等级规范）。
3. 三大文化符号：甲骨文（最早成熟文字）、青铜器（国之重器）、诗经（最早诗歌总集）。
4. 共和行政（前 841）是中国确切纪年开始。
5. 烽火戏诸侯→犬戎破镐京→平王东迁（前 770），西周终，东周始。
