# 宋辽夏金元 · 多政权并立到大一统

> "华夏民族之文化，历数千载之演进，造极于赵宋之世。" ——陈寅恪

960 年北宋建立到 1368 年元亡，共 408 年。这是中国历史上少有的**多民族政权并立**时期——宋、辽、夏、金先后与中原王朝对峙，最后由元完成大一统。期间经济重心南移完成、市民文化兴起、理学成型，但军事上始终疲弱，最终被游牧民族两次征服。

## 一、北宋（960—1127）

### 1. 陈桥兵变与"杯酒释兵权"

- 960 年后周禁军统帅赵匡胤**陈桥兵变**，黄袍加身，回师汴梁代周建宋，是为**宋太祖**。
- 鉴于五代武将篡位成风，他**杯酒释兵权**：宴会上以厚禄换兵权，把宿将石守信等解职，从此**重文抑武**成为宋朝国策。
- 制度设计：
  - **二府三司**：中书门下（政事堂）主行政、枢密院主军政、三司主财政，分割相权。
  - 路级设"帅（安抚使）、漕（转运使）、宪（提点刑狱）、仓（提举常平）"四监司互相牵制。
  - 守内虚外：禁军半数集中京师，边防较弱。
  - 科举大扩：录取名额比唐扩十余倍，社会上升通道空前畅通，士大夫阶层兴起。

### 2. 北宋三大问题

北宋虽然经济文化鼎盛，但自始至终有三大顽疾：

| 问题 | 表现 | 后果 |
| ---- | ---- | ---- |
| 冗官 | 一职多官、科举扩、恩荫广 | 财政吃紧 |
| 冗兵 | 招流民为兵，常备军百万 | 战斗力低下，财政重负 |
| 冗费 | 三项叠加 + 岁币 + 宗室 | 国库空虚 |

### 3. 北宋三大变法

#### 庆历新政（1043—1045）

范仲淹主持，10 项改革以"明黜陟、抑侥幸、精贡举"为主，触动既得利益，仅一年多即废。

#### 王安石变法（1069—1085）

宋神宗任命王安石为相，推行"**富国强兵**"新法：

| 法名 | 内容 | 目的 |
| ---- | ---- | ---- |
| 青苗法 | 春贷秋还，抑制高利贷 | 抑兼并、济贫民 |
| 募役法 | 出钱代役 | 农民归田 |
| 方田均税法 | 重新丈量土地 | 增税源 |
| 市易法 | 国家设市易司平抑物价 | 调节市场 |
| 保甲法 | 农民十家一保，平时农耕战时为兵 | 寓兵于农 |
| 将兵法 | 替代更戍法，固定将领带兵 | 提升战力 |

> 争议：变法触犯大官僚地主利益，司马光等**旧党**激烈反对；新法执行中变形扰民；元丰末神宗死、哲宗即位、高太后听政，司马光尽废新法；之后**新旧党争**反复撕扯，直至北宋亡。

### 4. 北宋的灭亡

- 与金约盟**海上之盟**（1120）共灭辽。
- 辽亡后金以宋"失约"为由南下，1127 年破开封，掳徽宗、钦宗及宗室后宫数千人北去，史称**靖康之变**，北宋亡。
- 钦宗弟赵构（宋高宗）南渡建康后定都临安（今杭州），南宋开始。

## 二、南宋（1127—1279）

### 1. 偏安江南

- 高宗畏金，杀岳飞求和（1141），向金称臣，**绍兴和议**：宋为"臣"、贡岁币银 25 万两、绢 25 万匹、淮水为界。
- 此后宋金几次北伐皆败：隆兴北伐（1163）、开禧北伐（1206）。
- 1206 年成吉思汗统一蒙古，金腹背受敌。

### 2. 南宋经济与文化

#### 经济重心南移完成

- "苏湖熟，天下足"——太湖流域成粮仓。
- 海上丝绸之路空前繁荣：泉州、广州、明州（宁波）三大港口；与 60 余国通商，关税占财政收入 1/5。
- 纸币**会子**广泛使用，是世界上最早的纸质本位货币雏形之一。

#### 市民文化

- 城市坊市界限打破，出现夜市、瓦子勾栏（娱乐区）。
- 词的全盛：李清照、辛弃疾、陆游、姜夔、吴文英。
- 话本、杂剧、南戏（戏文）登场，为元曲明清小说铺垫。
- 绘画：张择端《清明上河图》、马远、夏圭"残山剩水"。

### 3. 南宋灭亡

- 1234 年蒙古联宋灭金。
- 1235 年起蒙古攻宋，宋蒙战争 44 年。
- 1276 年元军入临安，宋恭宗降。
- 1279 年**崖山海战**：陆秀夫负幼帝赵昺投海，南宋亡。前后 319 年的赵宋王朝终结。

## 三、辽（916—1125）

### 1. 契丹崛起

- 耶律阿保机 916 年统一契丹八部，建**契丹国**（后改"辽"），947 改国号"辽"。
- 疆域东至日本海、西至阿尔泰、南抵燕云十六州。
- **燕云十六州**：936 后晋石敬瑭割让给契丹，使中原失去北部屏障，影响宋辽关系近 200 年。

### 2. 一国两制：南北面官

辽创造性地实行"以国制治契丹、以汉制待汉人"的**南面官北面官制**：北面官治契丹及其他游牧民族，以契丹习俗；南面官治燕云汉地，仿唐制。这是中国"一国两制"的最早雏形。

### 3. 澶渊之盟（1005）

- 1004 辽圣宗、萧太后南下，宋真宗亲征，双方在澶州对峙。
- 1005 年缔结**澶渊之盟**：宋辽约为兄弟，宋每年输辽银 10 万两、绢 20 万匹，称"岁币"；以白沟河为界。
- 此后 120 年宋辽无大战，双方经济文化交流繁荣。

### 4. 辽亡

- 1115 女真完颜阿骨打建金，"金"寓意契丹以铁为国号太轻。
- 金联宋灭辽，1125 辽天祚帝被擒，辽亡。
- 耶律大石率残部西迁，建立**西辽**（哈喇契丹），存 87 年，1218 年被蒙古所灭。

## 四、西夏（1038—1227）

- 党项族李元昊 1038 年称帝建**大夏**，都兴庆府（今宁夏银川），因在宋之西故称**西夏**。
- 创制西夏文，推广儒学，融汉、藏、佛文化。
- 与宋、辽多次战争，1044 年订立**庆历和议**：宋册封元昊为夏国王，岁赐银 7 万两、绢 15 万匹、茶 3 万斤。
- 后期与宋金之间反复周旋。1227 年被蒙古所灭，前后 190 年。

## 五、金（1115—1234）

- 女真完颜阿骨打 1115 年建金，都会宁（今黑龙江阿城）→ 中都（今北京）→ 汴。
- 实行**猛安谋克制**：300 户为一谋克、10 谋克为一猛安，**兵民合一**。
- 海陵王迁都中都（1153），北京从此成为大一统王朝都城起点。
- 1211 起蒙古攻金，1214 金迁都汴，1234 蒙宋联军灭金。

## 六、元朝（1271—1368）

### 1. 成吉思汗与蒙古崛起

- 1206 年**铁木真**在斡难河源召开忽里勒台大会，被推为**成吉思汗**，建立蒙古国。
- 创制蒙古文、颁布《大札撒》、设怯薛军、千户制整合部族。
- 西征：三次西征（1219—1223、1235—1242、1253—1260）建立四大汗国（钦察、察合台、窝阔台、伊儿）。
- 1227 年成吉思汗灭西夏时去世，1229 子窝阔台即位，1234 灭金，1241 西征至东欧。

### 2. 忽必烈建元

- 1260 年忽必烈在开平即位，1271 取《易经》"大哉乾元"之义定国号"**大元**"。
- 1272 迁都大都（今北京），奠定北京作为统一王朝首都的 700 年地位。
- 1279 崖山海战灭南宋，统一中国。
- **行省制**：设 10 行中书省，是今天"省"制的源头。
- 治理上首创"四等人制"：蒙古人、色目人（西域）、汉人（北方汉及女真契丹）、南人（南方汉）等级分明。

### 3. 元代社会

- **大运河**：截弯取直，从杭州直通大都，缩短 900 公里。
- **海漕**：江南粮海运至大都，刘家港（太仓）为大港。
- **驿站**：陆站水站遍布全国，丝路与驿站贯通欧亚，马可·波罗、伊本·白图泰东来。
- **宗教**：藏传佛教（八思巴）成国教；伊斯兰教进一步传播，回回民族成形；景教（也里可温）一度复兴。
- **文化**：元曲（关汉卿《窦娥冤》、王实甫《西厢记》、马致远《汉宫秋》）；王祯《农书》；郭守敬《授时历》（365.2425 日，与今公历同，比格里高利历早 300 年）；赵孟頫书画。

### 4. 元亡

- 元末顺帝怠政，黄河决口连年；权臣专横；阶级、民族矛盾激化。
- 1351 红巾军起义，刘福通、徐寿辉、张士诚、陈友谅、方国珍并起。
- 朱元璋投奔郭子兴，1356 据集庆（南京），采纳"高筑墙、广积粮、缓称王"策略。
- 1363 鄱阳湖大战灭陈友谅，1367 灭张士诚，1368 称帝建明，命徐达北伐。
- 1368 闰七月顺帝弃大都北逃，元亡（但北元仍存至 1635）。

## 七、四政权时代的关键特征

### 1. 多政权并立

| 政权 | 民族 | 时间 | 都城 |
| ---- | ---- | ---- | ---- |
| 宋 | 汉 | 960—1279 | 开封→临安 |
| 辽 | 契丹 | 916—1125 | 上京→中京 |
| 西夏 | 党项 | 1038—1227 | 兴庆府 |
| 金 | 女真 | 1115—1234 | 会宁→中都→汴 |
| 元 | 蒙古 | 1271—1368 | 大都 |

### 2. 民族融合加深

- 契丹、党项、女真汉化程度深；元朝色目人融入回族；蒙古族融入北方汉族较多。
- "汉儿"概念在元代扩展，胡汉混合是这阶段的常态。
- 现代中华民族格局的"多元一体"在这一阶段基本成型。

### 3. 中国经济文化重心南移完成

- 南方人口、税收、文化全面超过北方。
- 杭州、苏州、泉州、明州成为商业都会。
- **市民文化**兴起：勾栏瓦舍、话本、戏剧、风俗画。

## 八、文化成就

| 领域 | 代表 |
| ---- | ---- |
| 理学 | 周敦颐、张载、程颢程颐、朱熹、陆九渊；朱熹集大成 |
| 词 | 苏轼、李清照、辛弃疾、姜夔 |
| 诗 | 黄庭坚、陆游、元好问 |
| 散文 | 唐宋八大家中宋占六家（欧阳修、苏洵、苏轼、苏辙、王安石、曾巩） |
| 史学 | 司马光《资治通鉴》、郑樵《通志》 |
| 科技 | 三大发明完成（火药、指南针、印刷术的成熟与西传）；沈括《梦溪笔谈》 |
| 农业 | 陈旉《农书》；占城稻推广 |
| 数学 | 秦九韶、李冶、杨辉、朱世杰——宋元四大家 |
| 医学 | 宋慈《洗冤集录》（世界最早法医学） |
| 书画 | 张择端、赵孟頫、黄公望 |
| 戏曲 | 元曲四大家：关汉卿、白朴、马致远、郑光祖 |

> **重要**：火药、指南针、印刷术在宋元完成成熟与对外传播，**马克思说这三项发明预告了资产阶级社会的到来**——宋代市民经济与科技是中国古代科技的高峰。

## 九、延伸

- **成语**：黄袍加身、杯酒释兵权、半部论语治天下、澶渊之盟、靖康之耻、莫须有、留取丹心照汗青、崖山之后无中国（争议说法）。
- **典籍**：《资治通鉴》《梦溪笔谈》《洗冤集录》《授时历》《元史》《宋史》《辽史》《金史》。
- **遗址**：开封北宋东京城遗址、杭州南宋皇城遗址、西夏王陵、金中都遗址、元大都遗址、元上中都、泉州古城（世界遗产）。
- **影视**：电视剧《大宋提刑官》《精忠岳飞》《成吉思汗》；纪录片《契丹王朝》《苍狼》《河西走廊》后半段、《元朝帝国》。
- **必读人物**：赵匡胤、范仲淹、王安石、司马光、苏轼、岳飞、李清照、朱熹、陆游、辛弃疾、文天祥、成吉思汗、忽必烈、郭守敬、马可波罗、关汉卿、赵孟頫。

## 十、速记要点

1. 北宋 960—1127，南宋 1127—1279，共 319 年。
2. 辽 916—1125、西夏 1038—1227、金 1115—1234、元 1271—1368。
3. 北宋"重文抑武"造就文化盛世但军事疲弱。
4. 王安石变法是北宋最大改革，因新旧党争失败。
5. 澶渊之盟（1005）开宋辽 120 年和平。
6. 1279 崖山后南宋亡，元统一中国，行省制+北京为都奠定后世格局。
7. 三大发明（火药、指南针、印刷术）在宋元成熟并西传，影响世界近代史。
8. 理学+宋词+元曲是这阶段文化的三大代表。
