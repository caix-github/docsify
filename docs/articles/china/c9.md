# 明清 · 专制顶峰与近代前夜

> "九州生气恃风雷……我劝天公重抖擞，不拘一格降人才。" ——龚自珍

1368 年朱元璋建明，到 1912 年清帝退位，共 544 年。这是中国帝制社会的**晚期**——专制达到顶峰、疆域整合完成、人口爆炸；同时也是被西方赶超的关键时期。1840 年后，中国被迫从"天下"走向"万国"，进入近代。

## 一、明朝（1368—1644）

### 1. 建国与开国制度

- 1368 年朱元璋在南京称帝，国号"明"，是为明太祖。
- 1368 年徐达、常遇春北伐攻克大都，元顺帝北逃，元亡。
- 北逐元廷后多次用兵漠北，蓝玉捕鱼儿海之战（1388）大破北元主力。

#### 太祖集权

- **废丞相**：1380 年借胡惟庸案废中书省，**丞相一职从此废除**，六部尚书直接对皇帝负责。中国从此再无宰相。
- **设锦衣卫**：亲军+特务机构，开明代厂卫政治先河。
- **大杀功臣**：胡惟庸案、蓝玉案两案连坐数万，开国功臣几乎屠尽。
- **分封宗室**：分封 25 子弟于边镇，意图屏藩，反酿成靖难之役。
- **里甲制与黄册**：户籍十年一编，"画地为牢"式的乡村控制。
- **海禁**：限制民间海上贸易，奠定有明一代"海禁—开海"反复格局。

### 2. 靖难之役与永乐盛世

- 太孙建文帝即位后削藩，燕王朱棣 1399 年起兵"靖难"，1402 年攻破南京，建文帝下落不明。
- 朱棣即位，是为明成祖（永乐帝），1421 迁都北京。
- **永乐盛世**：
  - 五征漠北、派郑和下西洋（1405—1433，七下西洋）。
  - 编《永乐大典》（22877 卷，世界最大类书）。
  - 设**奴儿干都司**辖东北，设**乌思藏都司**辖西藏，**安南**一度设布政使司。
  - 迁都北京，天子守国门。

### 3. 仁宣之治（1424—1435）

仁宗、宣宗在位 11 年，停罢下西洋、慎用兵、整顿吏治，与民休息，史称"仁宣之治"。

### 4. 中期乱象（1435—1572）

- **土木之变**（1449）：英宗亲征瓦剌，在土木堡被俘，于谦拥景帝、坚守北京，瓦剌退。后被释回朝的英宗夺门之变复辟。
- **宦官专权**：王振、汪直、刘瑾、魏忠贤等，"厂卫"政治黑暗。
- **倭患**：嘉靖年间（16 世纪中叶）东南倭寇猖獗，戚继光、俞大猷平定；后隆庆开关（1567）海禁松，倭患渐息。
- **张居正改革**（1572—1582）：
  - **考成法**：官员考绩严格化。
  - **一条鞭法**：将田赋、徭役合并折银，按亩征收，简化税制，是税制史一大革命。
  - 清丈田亩，国库充盈，万历中兴。
  - 死后遭清算，新政尽废。

### 5. 万历怠政与晚明危机

- 万历帝在位 48 年，后 28 年**怠政不朝**，缺官不补，政令积压。
- **三大征**（1592—1600）：平哱拜、平朝鲜壬辰倭乱（丰臣秀吉侵朝）、平播州杨应龙——明军全胜但财政枯竭。
- **东林党争**：东林党与齐楚浙党阉党混斗，朝政瘫痪。
- **明末三饷**：辽饷、剿饷、练饷加派，民变四起。

### 6. 明亡

- **后金崛起**：1616 努尔哈赤建后金，1636 皇太极改国号"清"。
- **农民起义**：1627 起，李自成、张献忠并起。1644 李自成破北京，崇祯帝自缢煤山，明亡。
- **南明抗清**：1644—1662，弘光、隆武、鲁监国、永历政权相继败亡，郑成功据台湾坚持到 1683。

## 二、清朝（1636/1644—1912）

### 1. 入关与初建

- 1644 年吴三桂引清军入关，山海关之战李自成败走，多尔衮迎顺治帝入北京。
- 1644—1683 平定全国：灭南明、平三藩（1673—1681）、收台湾（1683）。
- 制度：
  - **议政王大臣会议**（早期）→ **南书房**（康熙）→ **军机处**（雍正起）：皇权愈发集中。
  - **六部+理藩院**：理藩院专管蒙古、西藏、回部事务。
  - **密折制度**：官员可绕过层级直达天听。
  - **文字狱**：康雍乾三朝大狱，思想钳制空前。
  - **摊丁入亩**（1723）：废除人头税，丁银并入田赋，人口爆炸性增长。

### 2. 康乾盛世（1662—1795）

清圣祖玄烨（康熙）8 岁即位，14 岁亲政，在位 61 年（最长）。清高宗弘历（乾隆）在位 60 年加 3 年太上皇。**康雍乾盛世**横跨 134 年，是中国古代盛世的尾声。

#### 康熙

- 平三藩（1673—1681）、收台湾（1683）、抗击沙俄（雅克萨之战）、三征噶尔丹（1690—1697）。
- 与俄罗斯签**《尼布楚条约》**（1689），是中国第一国际条约，划定东段边界。
- 倡理学、修《古今图书集成》《康熙字典》《全唐诗》。
- 1712"**盛世滋生人丁永不加赋**"，为摊丁入亩铺垫。

#### 雍正

- 在位 13 年，勤政。
- **摊丁入亩**、**改土归流**（西南土司改州县）、**火耗归公**、**养廉银**。
- **军机处**正式设立，君主专制顶峰。
- **文字狱**最严酷：曾静案、吕留良案。

#### 乾隆

- 十全武功：两平准部、一定回部、两打金川、靖台湾、降缅甸、降安南、两降廓尔喀——疆域鼎盛。
- **疆域整合**：1757 灭准噶尔，统一北疆；1759 平大小和卓，统一南疆；设**伊犁将军**；**驻藏大臣**（1727 起）；改土归流深至西南腹地。奠定今日中国版图。
- 《四库全书》（1773—1787 编成）——3.6 万种典籍总汇，但编修过程中大量"禁毁"书籍。
- 1793 英国马戛尔尼使团访华，乾隆"天朝物产丰盈，无所不有"——错失与世界工业革命接轨的机会。

### 3. 清中后期困局（1796—1840）

- **白莲教起义**（1796—1804）：九年战乱，耗银 2 亿两，清朝由盛转衰。
- **人口压力**：道光时人口突破 4 亿，人均耕地降至 1.5 亩警戒线以下。
- **吏治败坏**：和珅案、议罪银、捐输泛滥。
- **闭关锁国**：仅留广州一口通商（1757—1842），与西方工业革命失之交臂。

## 三、1840—1912：晚清的近代转型

> 详细的近代史内容请见 [c10 近现代](articles/china/c10.md)。本节仅就晚清部分略述。

### 1. 鸦片战争与不平等条约体系

- **第一次鸦片战争**（1840—1842），签《南京条约》：割香港、开五口、赔 2100 万银元、协定关税。
- **第二次鸦片战争**（1856—1860），火烧圆明园，签《天津条约》《北京条约》，俄国趁火打劫割走东北西北 150 万平方公里。
- 沉沦为半殖民地半封建社会。

### 2. 太平天国与洋务运动

- **太平天国**（1851—1864）：洪秀全建都天京（南京），《天朝田亩制度》《资政新篇》——中国近代革命预演。曾国藩湘军、李鸿章淮军平定。
- **洋务运动**（1861—1895）：曾、李、左、张之洞等"自强""求富"，办江南制造局、福州船政、北洋海军、汉阳铁厂。**中学为体西学为用**。
- **甲午战争**（1894—1895）：北洋海军全军覆没，《马关条约》割台湾、赔 2 亿两。
- **戊戌变法**（1898）：康梁谭嗣同"百日维新"，103 天失败，"六君子"殉难。

### 3. 义和团与清末新政

- **义和团运动**（1899—1901）：扶清灭洋，八国联军侵华，《辛丑条约》赔 4.5 亿两，主权尽失。
- **清末新政**（1901—1911）：废科举（1905）、预备立宪、编新军、修铁路。
- 1911 **辛亥革命**：武昌起义，1912 年元旦**中华民国**成立，2 月 12 日清宣统帝退位，清朝 268 年终结。

## 四、明清制度的总体特征

| 维度 | 明 | 清 |
| ---- | -- | -- |
| 中央 | 废相、内阁、司礼监、厂卫 | 议政王大臣会议→军机处、密折 |
| 地方 | 布政使司→督抚→府县 | 督抚→藩臬→府县 |
| 选官 | 科举鼎盛，八股取士 | 科举延续至 1905 |
| 财税 | 一条鞭法 | 摊丁入亩、火耗归公 |
| 军事 | 卫所制→募兵（营兵） | 八旗+绿营→湘淮军→新军 |
| 思想 | 王阳明心学、明末清初三大思想家 | 理学为尊、考据学（乾嘉学派） |
| 对外 | 海禁—开海反复 | 闭关—开埠 |

## 六、几条时代主线

### 1. 专制不断加强

明废相、清设军机处、文字狱、密折——皇帝权力至清雍正到达顶点。这是政治层面的"内向化"。

### 2. 疆域整合完成

清代奠定今日中国版图——满、蒙、疆、藏与内地同属一个政治共同体，是现代中国主权继承的基础。

### 3. 人口与经济的悖论

- 引入番薯、玉米、马铃薯后人口爆炸：明末 1.5 亿 → 道光 4 亿 → 1900 4.5 亿。
- 但人均耕地反降，无工业吸收，陷入"内卷化"（involution）。

### 4. 错失大航海与工业革命

- 郑和之后再无国家主导远航；明末海禁、清初迁界禁海；乾隆闭关锁国。
- 19 世纪西方进入工业革命时，中国仍在传统农业社会框架内打转。

## 八、速记要点

1. 明 1368—1644，清 1644—1912，合计 544 年。
2. 明废相、清设军机处，专制达顶峰。
3. 永乐盛世、仁宣之治、康乾盛世是三大高光时刻。
4. 一条鞭法（明）+ 摊丁入亩（清）是税制两大革命。
5. 1840 鸦片战争是中国近代开端；1912 清帝退位，帝制结束。
6. 四大名著中除《红楼梦》外，明小说独占其三；《红楼梦》是清代巅峰。
7. 明清闭关政策使中国错失工业革命先机，为近代落后埋下伏笔。
