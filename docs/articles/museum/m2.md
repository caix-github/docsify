# 南汉二陵博物馆参观记

这次参观沿着两条线索展开：一条是五代十国时期岭南政权南汉的兴衰，另一条是广州与岭南更长的历史。展厅中的陵墓、器物和城市记忆，让“南汉”不再只是历史书里一个短短的国名，也让人看到广州如何在王朝更替和南北交通中持续发展。

## 第一部分：南汉——五代十国中的岭南政权

### 从刘隐到南汉建国

唐朝灭亡后，中国进入五代十国时期。北方政权更替频繁，南方则出现多个地方政权。南汉以广州为中心，统治岭南地区，是十国之一。

南汉的建立与刘氏家族在岭南的势力增长有关。刘隐先后控制岭南重要地区，为家族建立政权奠定基础；他去世后，其弟刘龑于 917 年称帝，最初国号为“大越”，次年改国号为“汉”，史称南汉。都城设在兴王府，即今天的广州一带。

因此，刘隐是南汉建立前的重要奠基者，刘龑才是正式建国的君主。部分史料和纪念称号会把刘隐尊为太祖，但他与称帝建国的刘龑并非同一角色。

### 刘氏政权世系与南汉兴亡

| 人物 | 在位情况 | 历史线索 |
| --- | --- | --- |
| 刘隐 | 南汉建国前掌握岭南军政势力，未正式称帝 | 为刘氏政权奠基，死后被尊为太祖 |
| 刘龑（刘岩） | 917 年称帝，次年改国号为汉；在位至 942 年 | 南汉正式建立，定都兴王府 |
| 刘玢 | 942—943 年在位 | 在宫廷政变中被杀 |
| 刘晟 | 943—958 年在位 | 通过宫廷斗争取得皇位，继续统治南汉 |
| 刘鋹 | 958—971 年在位 | 南汉末代君主；971 年宋军攻取广州，南汉灭亡 |

南汉正式称帝的君主共有四位，刘隐是建国前的奠基者。南汉维持了半个多世纪。971 年，北宋军队南下攻取广州，刘鋹投降，南汉并入宋朝版图。政权的结束并不意味着广州失去重要性；相反，广州继续作为岭南政治、经济和对外交通的重要中心发展。

这段历史还要放回唐末的大背景中看。黄巢起义加剧了唐朝后期的动荡，907 年朱温代唐，五代十国时期由此开始。前蜀的建立者王建则是同一时期的另一位割据君主；他与南汉并非同一政权，而是南北多个地方政权并立的例子。

### 德陵、康陵与陵墓展陈

博物馆以南汉陵墓为重要主题。参观笔记记录了两座陵墓及其对应人物：

- **德陵**：与刘隐相关。
- **康陵**：与南汉高祖刘龑相关。

这两座陵墓帮助我们认识南汉王室的葬制、陵园营建和政治表达。墓葬不是单纯的“埋葬地点”：墓室结构、随葬品和葬仪往往反映了当时的等级观念、工艺水平和统治者对身后秩序的安排。

需要注意的是，南汉共有五位君主，但博物馆名称中的“二陵”指的是相关考古发现和展示的两座陵墓，不应据此推断五位君主的陵墓都已找到。涉及其他君主陵寝或称号时，应以考古报告和展厅说明为准。

### 南汉时期的佛教与文化

南汉时期岭南佛教发展活跃。展陈提到的禅宗“五家”，通常指沩仰宗、临济宗、曹洞宗、云门宗和法眼宗。这些宗派在唐末五代至宋初的禅宗发展中逐渐形成各自的传承和风格。

五代十国虽然政治上分裂，却不是文化停顿的时代。南方不少地区相对稳定，地方政权兴建寺院、支持工艺与贸易，佛教和区域文化也在这样的环境中传播。阅读南汉史时，可以同时观察政权更替与城市、宗教和经济的持续发展。

## 第二部分：从广州古城到岭南文物

### 广州的早期城市记忆

广州的城市历史可以追溯到秦代。秦统一岭南后设置南海郡，郡治番禺是早期广州城市发展的重要起点。南越国时期，番禺成为岭南政权的都城，城市与珠江水系、海上交通联系紧密。此后的广州经历多个朝代更替，逐渐发展成重要的区域中心。

广州还有“羊城”“五羊城”等别称。五羊衔谷、仙人降临楚庭的故事，是流传广泛的城市传说，表达了人们对丰收和安定生活的祝愿；它属于传说传统，不等于广州建城的考古年代证据。

### 以器物看见更长的历史

展览中的器物横跨多个时期。笔记记录了红山、大汶口、良渚、夏家店下层、殷墟、三星堆—金沙以及周边地区的对照展品。它们让观众看到中国早期文明并非只有一条单线：不同区域各自发展，也形成交流。

参观笔记还记下了若干岭南及相关历史器物和名词，例如：

- **马王堆汉墓**：位于长沙，出土的丝织品、漆器等展现了汉代手工业和贵族生活。它是用于比较理解汉代物质文化的例子，并非广州南汉墓葬。
- **南越国遗存**：南越国以番禺为都，相关考古发现为研究秦汉时期岭南政权、城市生活和区域交流提供了重要材料。
- **木构水闸与陶瓷、漆器**：水利设施与日用器物能呈现当时的城市管理、生产技术和生活习惯。

博物馆常用不同地区或不同时代的器物进行对照。看到展品时，可以留意它的年代、出土地和用途：展柜放在一起，不代表它们来自同一座墓或同一个政权。

### 从日常器物理解古人的生活

笔记中还列出鸡首壶、买地券、墓志、壶门、陶俑和“六畜”等展品线索。它们把宏大的历史落到普通生活和社会观念上：

- **鸡首壶**：壶身带有鸡首形流口，是古代陶瓷器的一种造型。其具体年代和用途需结合展签判断。
- **买地券**：随葬文书的一类，记载墓地购买或占有的象征性契约，反映古人对墓地、土地和死后世界的观念。
- **墓志**：刻写墓主身份、生平或家世的文字材料，是研究个人经历、家族关系和时代制度的重要史料。
- **壶门**：建筑或器物上呈壶形、曲线形的开口装饰。它既是造型元素，也能帮助观察不同时期的工艺和审美。
- **陶制六畜**：鸡、鸭、鹅、牛、羊、猪等家畜家禽形象，提示农业社会的生产结构、饮食来源和随葬习俗。

这些展品不只是“古物”，也是古人留下的生活记录。文字和器物相互参照，能够帮助我们把王朝史与真实的人、家庭和生计联系起来。

### 从古籍和遗迹补足地方史

参观笔记还记录了刘恂及其《岭表录异》。这部唐末五代之际的岭南见闻著作，记述当地物产、风俗和奇闻，为后人了解岭南自然环境与社会生活提供了文字线索。与墓葬出土的器物相比，古籍能讲述更具体的名称和故事；但它也有作者视角和时代局限，需要与考古材料互相参照。

笔记中提到的东铁塔、贺州花纹砖等展品，也提示岭南历史不只发生在广州城内。遗址、建筑构件和地方器物各自关联不同地点与年代，观看时可以留意展签上的出土地、年代和用途，不必把所有展品都归入南汉二陵本身。

## 参观后的收获：从一座陵墓读一座城市

南汉二陵让我从墓葬进入五代十国的政治史，再从南汉走回广州更早的城市记忆。刘氏家族在岭南建立政权，广州成为南汉都城；政权并入宋朝后，城市仍沿着珠江和海上交通继续发展。器物则提醒我们，历史并不只有帝王和战争，也包括工匠的技术、家庭的生活、宗教信仰和城市建设。

参观一座历史博物馆，可以尝试把三件事连起来：**展品是什么、它来自哪个时代、它能说明怎样的生活或制度**。这样既不会把不同年代的文物混为一谈，也能从一件器物逐步读出一段更完整的历史。
