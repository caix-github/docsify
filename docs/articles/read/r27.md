# 《晚熟的人》读后感

莫言的《晚熟的人》由多个乡村故事组成，人物各有命运，故事里既有生活的粗粝，也有世情的复杂。读这些故事时，我记住了一个失去右手、改用左手制作利器的年轻人：他朴实、勤劳，靠着坚持一件件做出自己的作品；也看见有人因嫉妒他人的才华而游手好闲、荒废正事，以及有人冷淡而虚荣，为了利益不择手段。这些人物并不只是善恶分明的符号，他们让人看到，在相似的生活环境里，不同的人会作出截然不同的选择。

## 用左手继续生活：勤劳与坚韧

失去右手，对一个需要动手谋生的人而言，意味着生活突然多了许多障碍。故事中的年轻人没有停留在失去带来的挫折里，而是学着用左手工作，继续打造一把又一把利器。这个细节让我印象深刻：他并非没有遭遇不幸，而是在不幸之后仍然努力寻找能够走下去的办法。

他的坚韧不是一句响亮的口号，而是在反复练习、认真做事中体现出来的。每一件作品都凝结着耐心，也证明一个人没有轻易向命运交出自己的生活。读到这里，我想到，真正的坚强未必是从不受伤，而是在处境改变后，仍愿意学习、适应，并把手头的事情做好。

## 嫉妒与虚度：把目光从别人身上收回来

笔记中提到，有人嫉妒表弟的才华，却游手好闲、不务正业。这样的对照让我觉得，嫉妒最先消耗的往往是嫉妒者自己：把心思放在别人的长处上，却不肯用行动改善自己的处境，最后只会让差距变得更明显。

羡慕别人并不可怕，它有时能让人看见自己向往什么；真正让人停滞的，是把羡慕变成怨恨，再用怨恨代替努力。与其盯着别人已经拥有的东西，不如把注意力收回来，找到自己能做的一件小事，从中积累能力与信心。才华固然可贵，但持续投入和踏实行动同样重要。

## 为了利益失去分寸

故事中还有冷淡、爱慕虚荣、追逐利益而不择手段的人物。这样的选择令人反感，却也让人看见，利益和虚荣很容易成为衡量生活的单一尺度：当一个人只想着得到更多、显得更体面，就可能把他人的感受和自己的底线抛在一边。

这些人物带来的提醒并不只是“不要贪心”。更重要的是，在追求目标时仍要记得问自己：得到某样东西，需要付出什么代价？如果为了利益伤害别人、背离原则，即便一时占了便宜，也未必能获得真正踏实的生活。一个人的选择会慢慢塑造他，也会影响他与周围人的关系。

## 读后感：什么样的成熟值得期待

书名《晚熟的人》让我想到，成熟并不只是年纪增长，也不是学会圆滑地应付世事。真正的成熟，或许是经历生活的限制与诱惑之后，仍然愿意认真做事、承担选择的后果，并保有对他人的体谅。那个失去右手却仍用左手劳作的年轻人，让我看到逆境中的坚韧；嫉妒他人、虚度光阴的人，则让我看到不行动如何困住自己；一味追逐虚荣和利益的人，又提醒我别把得失当成人生唯一的尺度。

《晚熟的人》通过不同的乡村故事呈现了人性的复杂，也让我反思自己面对挫折、比较和诱惑时会如何选择。我们未必能决定起点和际遇，却可以努力决定怎样回应它们：遇到困难时多一些坚持，看到别人的长处时把羡慕化为行动，追求目标时守住做人的分寸。成长也许缓慢，但只要不停止学习与自省，晚一点成熟，也依然可以走向更踏实、更清醒的人生。
