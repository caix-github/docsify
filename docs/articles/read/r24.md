# 《西瓜船》读后感

《西瓜船》的第一章从一场买瓜引出的冲突写起：一位妇人买下西瓜，事情却一步步失控。卖瓜的福三被妇人的儿子刺伤，最终不治身亡。一个看似寻常的生活插曲，转眼变成无法挽回的悲剧。福三的母亲承受丧子之痛，却没有让仇恨支配自己；她千里寻来，想找回儿子遗失的西瓜。这个故事让我看到，一只西瓜牵起了几个人的命运，也让人重新思考冲突、伤害与宽恕。

## 一只西瓜引出的悲剧

故事最令人唏嘘的地方，是悲剧起初并不宏大。它从日常生活里的买卖和争执开始，却因为冲动与暴力走向死亡。无论最初的矛盾是什么，动手伤人都让问题越过了可以挽回的界线。福三失去了生命，他的母亲失去了儿子；而施暴者及其家人，也必须面对这份沉重后果。

读到这里，我感受到一个朴素却重要的提醒：情绪可以来得很快，后果却可能持续一生。争执时，人容易只顾着证明自己有理，忘记对方也是一个有亲人、有生活的人。冷静下来、停一停、选择沟通，往往比一时逞强更需要勇气。任何矛盾都不值得用暴力解决，因为伤害一旦发生，许多东西就再也回不到原来的样子。

## 放下仇恨，不等于忘记伤痛

福三母亲的选择尤其打动我。失去儿子的痛苦没有消失，她也没有理由假装一切都未发生；但她没有把余生完全交给仇恨，而是踏上漫长的寻找之路。她寻找的不只是一只西瓜，也像是在寻找与儿子有关的记忆、牵挂，以及让自己继续走下去的力量。

宽恕并不是替伤害开脱，更不是说责任不重要。福三的死依然是真实的，造成伤害的人也不能因此免于承担后果。真正难得的是，在承受巨大痛苦之后，福三的母亲仍愿意把目光从仇恨上移开，去做一件与爱和牵挂有关的事。她的选择让我明白，放下仇恨不是否认伤痛，而是不让伤痛成为自己唯一的生活。

## “西瓜船”承载的牵挂

西瓜在故事里既是引发事件的物件，也是连接人物命运的线索。想到“西瓜船”这个名字，我会把它看作一艘载着记忆的小船：它从一次偶然的相遇出发，经过冲突与失去，最后把人带到关于亲情、悲悯和和解的思考之中。

这艘“船”并不能带人回到悲剧发生之前，也不能让失去的人重新回来。但寻找的过程仍有意义，因为它让活着的人有机会面对伤痛、记住逝者，并试着重新与世界建立联系。一个普通的西瓜因此有了超出物件本身的分量：它提醒我，生活中看似微不足道的事，也可能牵动许多人的情感与命运。

## 读后感：在冲突中守住善意

读完这一章，我最深的感受是惋惜，也有敬佩。惋惜的是，一场本可以停下来的冲突，最终夺走了福三的生命；敬佩的是，福三的母亲身处悲痛之中，仍努力选择不被仇恨吞没。

我们未必能左右所有遭遇，却可以努力决定如何回应冲突。遇到争执时，多一点克制，少一点逞强；面对伤害时，既要承认事实、承担责任，也尽可能不给仇恨继续扩大的机会。《西瓜船》让我看到，善意并不能抹去悲剧，却能让悲剧之后的人生不只剩下怨恨。愿我们都能珍惜平凡日常里的相遇，在情绪涌上来时停一停，也在经历伤痛之后，仍保留理解他人、继续生活的力量。
